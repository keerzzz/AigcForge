---
title: 策略
description: 控制 Aigcfroge 可以使用的已配置资源。
---

策略控制 Aigcfroge 是否可以对指定资源执行操作。此功能处于实验阶段，通过 `aigcfroge.json` 中的 `experimental.policies` 数组进行配置。

策略与[权限](/docs/permissions)是分开的。权限控制工具在会话期间可以做什么，而策略控制 Aigcfroge 是否可以使用诸如 LLM 提供商之类的资源。

---

## 配置

每条策略语句包含三个字段：

- `effect` - 取值 `"allow"` 或 `"deny"`。
- `action` - 被控制的操作。
- `resource` - 该语句所应用的资源 ID 或通配符模式。

例如，禁止使用 `openai` 提供商：

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "experimental": {
    "policies": [
      {
        "effect": "deny",
        "action": "provider.use",
        "resource": "openai"
      }
    ]
  }
}
```

被策略拒绝的提供商无法用于模型选择或模型使用，即使它拥有凭据或已正确配置。

---

## 可用策略

Aigcfroge 目前支持一种策略操作：

| 操作           | 资源                              | 描述                             |
| -------------- | --------------------------------- | -------------------------------- |
| `provider.use` | 提供商 ID，例如 `openai`          | 允许或禁止使用 LLM 提供商。      |

未来可能会添加更多策略操作。

---

## 匹配

`resource` 字段支持通配符匹配。使用 `*` 匹配零个或多个字符，使用 `?` 匹配一个字符。

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "experimental": {
    "policies": [
      {
        "effect": "deny",
        "action": "provider.use",
        "resource": "company-*"
      }
    ]
  }
}
```

这会禁止 `company-us` 和 `company-eu` 等提供商。

---

## 规则顺序

当多条语句匹配时，最后匹配的语句生效。请将宽泛的规则放在前面，然后在它们之后放置更具体的例外。

例如，仅允许 Anthropic：

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "experimental": {
    "policies": [
      {
        "effect": "deny",
        "action": "provider.use",
        "resource": "*"
      },
      {
        "effect": "allow",
        "action": "provider.use",
        "resource": "anthropic"
      }
    ]
  }
}
```

如果没有策略匹配某个提供商，则默认允许使用该提供商。

策略可以在您的全局配置和项目配置中同时设置。如果两个位置的策略匹配同一提供商，您的全局策略优先于项目策略。这样可以防止某个仓库重新启用您在全局禁止的提供商。

---

## 提供商列表

在控制提供商访问时，请使用策略而不是旧的 `disabled_providers` 和 `enabled_providers` 设置。

要替换 `disabled_providers`：

```json title="aigcfroge.json"
{
  "experimental": {
    "policies": [
      { "effect": "deny", "action": "provider.use", "resource": "openai" },
      { "effect": "deny", "action": "provider.use", "resource": "google" }
    ]
  }
}
```

要替换 `enabled_providers`，请先禁止所有提供商，然后允许选中的提供商：

```json title="aigcfroge.json"
{
  "experimental": {
    "policies": [
      { "effect": "deny", "action": "provider.use", "resource": "*" },
      { "effect": "allow", "action": "provider.use", "resource": "anthropic" },
      { "effect": "allow", "action": "provider.use", "resource": "openai" }
    ]
  }
}
```
