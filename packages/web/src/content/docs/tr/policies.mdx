---
title: Politikalar
description: Aigcfroge'un hangi yapılandırılmış kaynakları kullanabileceğini kontrol edin.
---

Politikalar, Aigcfroge'un adlandırılmış bir kaynak üzerinde bir eylem gerçekleştirip gerçekleştiremeyeceğini kontrol eder. Bu özellik deneyseldir ve `aigcfroge.json` içindeki `experimental.policies` dizisiyle yapılandırılır.

Politikalar [izinlerden](/docs/permissions) ayrıdır. İzinler, araçların bir oturum sırasında neler yapabileceğini kontrol ederken, politikalar Aigcfroge'un bir LLM sağlayıcısı gibi bir kaynağı kullanıp kullanamayacağını kontrol eder.

---

## Yapılandırma

Her politika ifadesinin üç alanı vardır:

- `effect` - `"allow"` veya `"deny"` değerlerinden biri.
- `action` - Kontrol edilen işlem.
- `resource` - İfadenin uygulandığı kaynak kimliği veya joker karakter kalıbı.

Örneğin, `openai` sağlayıcısının kullanımını reddetmek için:

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "experimental": {
    "policies": [
      {
        "effect": "deny",
        "action": "provider.use",
        "resource": "openai"
      }
    ]
  }
}
```

Politika tarafından reddedilen bir sağlayıcı, kimlik bilgileri olsa veya başka şekilde doğru yapılandırılmış olsa bile model seçimi veya model kullanımı için kullanılamaz.

---

## Mevcut Politikalar

Aigcfroge şu anda bir politika eylemini destekler:

| Eylem          | Kaynak                        | Açıklama                            |
| -------------- | ----------------------------- | ----------------------------------- |
| `provider.use` | Provider ID, such as `openai` | Allow or deny use of an LLM provider. |

Gelecekte daha fazla politika eylemi eklenebilir.

---

## Eşleştirme

`resource` alanı joker karakter eşleştirmeyi destekler. Sıfır veya daha fazla karakterle eşleşmesi için `*` ve tam olarak bir karakterle eşleşmesi için `?` kullanın.

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "experimental": {
    "policies": [
      {
        "effect": "deny",
        "action": "provider.use",
        "resource": "company-*"
      }
    ]
  }
}
```

Bu, `company-us` ve `company-eu` gibi sağlayıcıları reddeder.

---

## Kural Sırası

Birden çok ifade eşleştiğinde, son eşleşen ifade kazanır. Geniş kuralları önce, daha spesifik istisnaları onlardan sonra koyun.

Örneğin, yalnızca Anthropic'e izin vermek için:

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "experimental": {
    "policies": [
      {
        "effect": "deny",
        "action": "provider.use",
        "resource": "*"
      },
      {
        "effect": "allow",
        "action": "provider.use",
        "resource": "anthropic"
      }
    ]
  }
}
```

Bir sağlayıcıyla hiçbir politika eşleşmezse, sağlayıcı kullanımına varsayılan olarak izin verilir.

Politikalar hem genel yapılandırmanızda hem de proje yapılandırmanızda ayarlanabilir. Her iki konumdaki politikalar aynı sağlayıcıyla eşleşirse, genel politikanız proje politikasının üzerinde önceliğe sahiptir. Bu, bir deponun genel olarak reddettiğiniz bir sağlayıcıyı yeniden etkinleştirmesini engeller.

## Sağlayıcı Listeleri

Sağlayıcı erişimini kontrol ederken daha eski `disabled_providers` ve `enabled_providers` ayarları yerine politikaları kullanın.

`disabled_providers` öğesini değiştirmek için:

```json title="aigcfroge.json"
{
  "experimental": {
    "policies": [
      { "effect": "deny", "action": "provider.use", "resource": "openai" },
      { "effect": "deny", "action": "provider.use", "resource": "google" }
    ]
  }
}
```

`enabled_providers` öğesini değiştirmek için önce tüm sağlayıcıları reddedin ve ardından seçilen sağlayıcılara izin verin:

```json title="aigcfroge.json"
{
  "experimental": {
    "policies": [
      { "effect": "deny", "action": "provider.use", "resource": "*" },
      { "effect": "allow", "action": "provider.use", "resource": "anthropic" },
      { "effect": "allow", "action": "provider.use", "resource": "openai" }
    ]
  }
}
```
