Referanslar, Aigcfroge'a geçerli projenin dışındaki dizinlere erişim sağlar. Çalışırken dokümantasyonu, paylaşılan kitaplıkları, örnekleri veya başka bir depoyu kullanılabilir kılmak için bunları kullanın.

Referanslar, `aigcfroge.json` veya `aigcfroge.jsonc` içinde takma adla yapılandırılır.

```jsonc title="aigcfroge.jsonc"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "references": {
    "docs": {
      "path": "../product-docs",
      "description": "Use for product behavior and documentation conventions",
    },
    "sdk": {
      "repository": "keerzzz/AigcForge-sdk-js",
      "branch": "main",
      "description": "Use for JavaScript SDK implementation details",
    },
  },
}
```

---

## Yerel dizinler

Yerel bir dizine referans vermek için `path` kullanın.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "docs": {
      "path": "../docs",
    },
  },
}
```

Yollar şunlar olabilir:

- Referansı tanımlayan yapılandırma dosyasına göre
- `/home/user/docs` gibi mutlak
- `~/docs` gibi ana dizininize göre

Ayrıca bir dize kısaltması da kullanabilirsiniz:

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "docs": "../docs",
  },
}
```

## Git depoları

Bir Git deposuna referans vermek için `repository` kullanın. Aigcfroge, depoyu yerel depo önbelleğinde somutlaştırır ve kullanıma alınan kaynağı bir referans dizini olarak kullanılabilir kılar.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "effect": {
      "repository": "Effect-TS/effect",
      "branch": "main",
    },
  },
}
```

`repository`, Git URL'lerini, ana bilgisayar/yol referanslarını ve GitHub `owner/repo` kısaltmasını kabul eder. İsteğe bağlı `branch` alanı bir dal veya ref seçer. `branch` olmadan Aigcfroge, deponun varsayılan dalını kullanır.

Bir dal, açıklama veya diğer seçeneklere ihtiyacınız olmadığında dize kısaltması kullanabilirsiniz:

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "effect": "Effect-TS/effect",
  },
}
```

:::note
Git referansları zaman uyumsuz olarak yenilenir. Yeni yapılandırılan bir deponun klonlama veya güncelleme işlemini bitirmesi bir an sürebilir.
:::

## Kullanımı açıklama

Bir agent'ın bir referansı ne zaman kullanması gerektiğini açıklamak için `description` ekleyin.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "design-system": {
      "path": "../design-system",
      "description": "Use when implementing UI components or design tokens",
    },
  },
}
```

Aigcfroge, açıklaması olan referansları agent bağlamına dahil eder. Açıklamalar, benzer içerikli referansları ayırt edebilecek kadar kısa ve spesifik olmalıdır. Açıklaması olmayan referanslar otomatik tamamlama ve doğrudan kullanım yoluyla kullanılabilir durumda kalır, ancak agent'lara tanıtılmaz.

---

## Otomatik tamamlama girişlerini gizleme

Bir referansı TUI'daki `@` otomatik tamamlamasından çıkarmak için `hidden` öğesini `true` olarak ayarlayın.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "internal": {
      "path": "../internal",
      "description": "Use for internal implementation details",
      "hidden": true,
    },
  },
}
```

`hidden` yalnızca otomatik tamamlamayı etkiler. Açıklaması olan gizli bir referans, agent bağlamına dahil edilmeye devam eder.

---

## Referansları kullanma

Yapılandırılan referanslar TUI `@` otomatik tamamlamasında görünür. Referans kökünü eklemek için `@alias`, içindeki dosyaları aramak için `@alias/` yazın.

```text
Compare this implementation with @sdk/src/client.ts
```

Agent'lar ayrıca sistem bağlamında açıklaması olan yapılandırılmış referansların çözümlenmiş yollarını ve açıklamalarını alır, böylece siz manuel olarak eklemeden ilgili olduğunda bir referansı inceleyebilirler.

Aigcfroge, harici dizin izin sınırı aracılığıyla referans dizinlerine otomatik olarak izin verir. Normal araç izinleri hâlâ geçerlidir; örneğin, dosyaları düzenleyemeyen bir agent, bir dizin referans olarak yapılandırıldığı için düzenleme erişimi kazanmaz.

## Yapılandırma alanları

| Alan         | Yerel | Git | Açıklama                                     |
| ------------- | ----- | --- | -------------------------------------------- |
| `path`        | Yes   | No  | Local reference directory                    |
| `repository`  | No    | Yes | Git URL, host/path, or GitHub `owner/repo` value |
| `branch`      | No    | Yes | Optional Git branch or ref                   |
| `description` | Yes   | Yes | Guidance describing when to use the reference |
| `hidden`      | Yes   | Yes | Hide the reference from TUI `@` autocomplete |

Referans takma adları boş olamaz veya `/`, boşluk, ters tik veya virgül içeremez.
