title: Referencias
description: Agregue directorios locales y repositorios Git como referencias del proyecto.
---

Las referencias le dan a Aigcfroge acceso a directorios fuera del proyecto actual. Úselas para poner a disposición documentación, bibliotecas compartidas, ejemplos u otro repositorio mientras trabaja.

Las referencias se configuran por alias en `aigcfroge.json` o `aigcfroge.jsonc`.

```jsonc title="aigcfroge.jsonc"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "references": {
    "docs": {
      "path": "../product-docs",
      "description": "Use for product behavior and documentation conventions",
    },
    "sdk": {
      "repository": "keerzzz/AigcForge-sdk-js",
      "branch": "main",
      "description": "Use for JavaScript SDK implementation details",
    },
  },
}
```

---

## Directorios locales

Use `path` para hacer referencia a un directorio local.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "docs": {
      "path": "../docs",
    },
  },
}
```

Las rutas pueden ser:

- Relativas al archivo de configuración que define la referencia
- Absolutas, como `/home/user/docs`
- Relativas a su directorio de inicio, como `~/docs`

También puede usar una abreviatura de cadena:

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "docs": "../docs",
  },
}
```

## Repositorios Git

Use `repository` para hacer referencia a un repositorio Git. Aigcfroge materializa el repositorio en su caché local de repositorios y hace que el código fuente descargado esté disponible como directorio de referencia.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "effect": {
      "repository": "Effect-TS/effect",
      "branch": "main",
    },
  },
}
```

`repository` acepta URL de Git, referencias de host/ruta y la abreviatura de GitHub `owner/repo`. El campo opcional `branch` selecciona una rama o ref. Sin `branch`, Aigcfroge usa la rama predeterminada del repositorio.

Puede usar la abreviatura de cadena cuando no necesite una rama, descripción u otras opciones:

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "effect": "Effect-TS/effect",
  },
}
```

:::note
Las referencias Git se actualizan de forma asíncrona. Un repositorio recién configurado puede tardar un momento en terminar de clonarse o actualizarse.
:::

## Describir el uso

Agregue `description` para explicar cuándo un agente debe usar una referencia.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "design-system": {
      "path": "../design-system",
      "description": "Use when implementing UI components or design tokens",
    },
  },
}
```

Aigcfroge incluye en el contexto de los agentes las referencias que tienen descripciones. Las descripciones deben ser breves y específicas para distinguir referencias con contenido similar. Las referencias sin descripciones siguen disponibles mediante el autocompletado y el uso directo, pero no se anuncian a los agentes.

---

## Ocultar entradas del autocompletado

Establezca `hidden` en `true` para omitir una referencia del autocompletado `@` en la TUI.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "internal": {
      "path": "../internal",
      "description": "Use for internal implementation details",
      "hidden": true,
    },
  },
}
```

`hidden` solo afecta al autocompletado. Una referencia oculta con descripción sigue incluida en el contexto de los agentes.

---

## Usar referencias

Las referencias configuradas aparecen en el autocompletado `@` de la TUI. Escriba `@alias` para adjuntar la raíz de la referencia, o `@alias/` para buscar archivos dentro de ella.

```text
Compare this implementation with @sdk/src/client.ts
```

Los agentes también reciben las rutas resueltas y las descripciones de las referencias configuradas que tienen descripciones en su contexto de sistema, para que puedan inspeccionar una referencia cuando sea relevante sin que usted la adjunte manualmente.

Aigcfroge permite automáticamente los directorios de referencia a través de su límite de permisos de directorio externo. Los permisos normales de las herramientas siguen aplicándose; por ejemplo, un agente que no puede editar archivos no obtiene acceso de edición porque un directorio esté configurado como referencia.

## Campos de configuración

| Campo         | Local | Git | Descripción                                      |
| ------------- | ----- | --- | ------------------------------------------------ |
| `path`        | Sí    | No  | Directorio de referencia local                   |
| `repository`  | No    | Sí  | URL de Git, host/ruta o valor `owner/repo` de GitHub |
| `branch`      | No    | Sí  | Rama o ref Git opcional                          |
| `description` | Sí    | Sí  | Orientación que describe cuándo usar la referencia |
| `hidden`      | Sí    | Sí  | Oculta la referencia del autocompletado `@` de la TUI |

Los alias de referencia no pueden estar vacíos ni contener `/`, espacios en blanco, comillas invertidas o comas.
