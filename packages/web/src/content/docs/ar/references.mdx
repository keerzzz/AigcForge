تمنح المراجع Aigcfroge إمكانية الوصول إلى الأدلة خارج المشروع الحالي. استخدمها لإتاحة الوثائق أو المكتبات المشتركة أو الأمثلة أو مستودع آخر أثناء العمل.

تُهيأ المراجع بواسطة اسم مستعار (alias) في `aigcfroge.json` أو `aigcfroge.jsonc`.

```jsonc title="aigcfroge.jsonc"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "references": {
    "docs": {
      "path": "../product-docs",
      "description": "Use for product behavior and documentation conventions",
    },
    "sdk": {
      "repository": "keerzzz/AigcForge-sdk-js",
      "branch": "main",
      "description": "Use for JavaScript SDK implementation details",
    },
  },
}
```

---

## الأدلة المحلية

استخدم `path` للإشارة إلى دليل محلي.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "docs": {
      "path": "../docs",
    },
  },
}
```

يمكن أن تكون المسارات:

- نسبية إلى ملف الإعدادات الذي يعرّف المرجع
- مطلقة، مثل `/home/user/docs`
- نسبية إلى دليل المنزل، مثل `~/docs`

يمكنك أيضًا استخدام صيغة مختصرة كنص:

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "docs": "../docs",
  },
}
```

---

## مستودعات Git

استخدم `repository` للإشارة إلى مستودع Git. يُجسّد Aigcfroge المستودع في ذاكرة التخزين المؤقت المحلية للمستودعات ويجعل المصدر المستخرج متاحًا كدليل مرجعي.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "effect": {
      "repository": "Effect-TS/effect",
      "branch": "main",
    },
  },
}
```

يقبل `repository` عناوين URL الخاصة بـ Git ومراجع المضيف/المسار وصيغة GitHub المختصرة `owner/repo`. يحدد الحقل الاختياري `branch` فرعًا أو ref. بدون `branch`، يستخدم Aigcfroge الفرع الافتراضي للمستودع.

يمكنك استخدام صيغة مختصرة كنص عندما لا تحتاج إلى فرع أو وصف أو خيارات أخرى:

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "effect": "Effect-TS/effect",
  },
}
```

:::note
تتم مزامنة مراجع Git بشكل غير متزامن. قد يستغرق المستودع المُهيأ حديثًا لحظة لإكمال الاستنساخ أو التحديث.
:::

## وصف الاستخدام

أضِف `description` لشرح متى يجب أن يستخدم الوكيل المرجع.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "design-system": {
      "path": "../design-system",
      "description": "Use when implementing UI components or design tokens",
    },
  },
}
```

يُدرج Aigcfroge المراجع التي تحتوي على أوصاف في سياق الوكيل. يجب أن تكون الأوصاف قصيرة ومحددة بما يكفي لتمييز المراجع ذات المحتوى المتشابه. تظل المراجع بدون أوصاف متاحة عبر الإكمال التلقائي والاستخدام المباشر، لكنها لا تُعلَن للوكلاء.

---

## إخفاء إدخالات الإكمال التلقائي

اضبط `hidden` على `true` لاستبعاد مرجع من الإكمال التلقائي لـ `@` في TUI.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "internal": {
      "path": "../internal",
      "description": "Use for internal implementation details",
      "hidden": true,
    },
  },
}
```

يؤثر `hidden` على الإكمال التلقائي فقط. يظل المرجع المخفي الذي يحتوي على وصف مشمولًا في سياق الوكيل.

---

## استخدام المراجع

تظهر المراجع المُهيأة في الإكمال التلقائي لـ `@` في TUI. اكتب `@alias` لإرفاق جذر المرجع، أو `@alias/` للبحث عن الملفات داخله.

```text
Compare this implementation with @sdk/src/client.ts
```

يتلقى الوكلاء أيضًا المسارات والأوصاف المُحللة للمراجع المُهيأة التي تحتوي على أوصاف في سياق النظام الخاص بهم، حتى يتمكنوا من فحص المرجع عندما يكون ذا صلة دون إرفاقه يدويًا.

يسمح Aigcfroge تلقائيًا بالأدلة المرجعية عبر حدود أذونات الدليل الخارجي. لا تزال أذونات الأدوات العادية سارية؛ على سبيل المثال، لا يكتسب الوكيل الذي لا يمكنه تعديل الملفات صلاحية التعديل لمجرد أن دليلًا ما مُهيأ كمرجع.

## حقول الإعداد

| الحقل         | محلي | Git | الوصف                                                    |
| ------------- | ---- | --- | -------------------------------------------------------- |
| `path`        | نعم  | لا  | دليل المرجع المحلي                                       |
| `repository`  | لا   | نعم | عنوان URL لـ Git، أو مضيف/مسار، أو قيمة `owner/repo` من GitHub |
| `branch`      | لا   | نعم | فرع أو ref اختياري من Git                                |
| `description` | نعم  | نعم | إرشادات تصف متى يجب استخدام المرجع                      |
| `hidden`      | نعم  | نعم | إخفاء المرجع من الإكمال التلقائي لـ `@` في TUI           |

لا يمكن أن تكون أسماء المراجع المستعارة فارغة أو أن تحتوي على `/` أو مسافات أو علامات backticks أو فواصل.
