As referências dão ao aigcfroge acesso a diretórios fora do projeto atual. Use-as para disponibilizar documentação, bibliotecas compartilhadas, exemplos ou outro repositório enquanto você trabalha.

As referências são configuradas por alias em `aigcfroge.json` ou `aigcfroge.jsonc`.

```jsonc title="aigcfroge.jsonc"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "references": {
    "docs": {
      "path": "../product-docs",
      "description": "Use for product behavior and documentation conventions",
    },
    "sdk": {
      "repository": "keerzzz/AigcForge-sdk-js",
      "branch": "main",
      "description": "Use for JavaScript SDK implementation details",
    },
  },
}
```

## Diretórios locais

Use `path` para referenciar um diretório local.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "docs": {
      "path": "../docs",
    },
  },
}
```

Os caminhos podem ser:

- Relativos ao arquivo de configuração que define a referência
- Absolutos, como `/home/user/docs`
- Relativos ao seu diretório home, como `~/docs`

Você também pode usar uma abreviação de string:

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "docs": "../docs",
  },
}
```

## Repositórios Git

Use `repository` para referenciar um repositório Git. O aigcfroge materializa o repositório em seu cache local de repositórios e disponibiliza o código-fonte clonado como um diretório de referência.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "effect": {
      "repository": "Effect-TS/effect",
      "branch": "main",
    },
  },
}
```

`repository` aceita URLs Git, referências de host/caminho e a abreviação `owner/repo` do GitHub. O campo opcional `branch` seleciona uma branch ou ref. Sem `branch`, o aigcfroge usa a branch padrão do repositório.

Você pode usar a abreviação de string quando não precisar de uma branch, descrição ou outras opções:

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "effect": "Effect-TS/effect",
  },
}
```

:::note
As referências Git são atualizadas de forma assíncrona. Um repositório recém-configurado pode levar um momento para terminar a clonagem ou atualização.
:::

## Descrever o uso

Adicione `description` para explicar quando um agente deve usar uma referência.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "design-system": {
      "path": "../design-system",
      "description": "Use when implementing UI components or design tokens",
    },
  },
}
```

O aigcfroge inclui referências com descrições no contexto do agente. As descrições devem ser curtas e específicas o suficiente para distinguir referências com conteúdo semelhante. Referências sem descrições continuam disponíveis por meio do autocompletar e do uso direto, mas não são anunciadas aos agentes.

## Ocultar entradas do autocompletar

Defina `hidden` como `true` para omitir uma referência do autocompletar `@` no TUI.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "internal": {
      "path": "../internal",
      "description": "Use for internal implementation details",
      "hidden": true,
    },
  },
}
```

`hidden` afeta apenas o autocompletar. Uma referência oculta com descrição permanece incluída no contexto do agente.

## Usar referências

As referências configuradas aparecem no autocompletar `@` do TUI. Digite `@alias` para anexar a raiz da referência ou `@alias/` para buscar arquivos dentro dela.

```text
Compare this implementation with @sdk/src/client.ts
```

Os agentes também recebem os caminhos resolvidos e as descrições das referências configuradas que possuem descrições em seu contexto de sistema, para que possam inspecionar uma referência quando ela for relevante, sem que você a anexe manualmente.

O aigcfroge permite automaticamente diretórios de referência por meio de seu limite de permissão de diretório externo. As permissões normais de ferramentas ainda se aplicam; por exemplo, um agente que não pode editar arquivos não ganha acesso de edição pelo fato de um diretório estar configurado como referência.

## Campos de configuração

| Campo         | Local | Git | Descrição                                       |
| ------------- | ----- | --- | ----------------------------------------------- |
| `path`        | Sim   | Não | Diretório de referência local                   |
| `repository`  | Não   | Sim | URL Git, host/caminho ou valor `owner/repo` do GitHub |
| `branch`      | Não   | Sim | Branch ou ref Git opcional                      |
| `description` | Sim   | Sim | Orientação que descreve quando usar a referência |
| `hidden`      | Sim   | Sim | Ocultar a referência do autocompletar `@` do TUI |

Os aliases de referência não podem ser vazios nem conter `/`, espaços em branco, crases ou vírgulas.
