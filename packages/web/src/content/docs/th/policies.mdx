---

นโยบายควบคุมว่า Aigcfroge อาจดำเนินการกับทรัพยากรที่มีชื่อหรือไม่ ฟีเจอร์นี้เป็นขั้นทดลองและกำหนดค่าด้วยอาร์เรย์ `experimental.policies` ใน `aigcfroge.json`

นโยบายแยกจาก [สิทธิ์](/docs/permissions) สิทธิ์ควบคุมว่าเครื่องมือสามารถทำอะไรได้บ้างระหว่างเซสชัน ส่วนนโยบายควบคุมว่า Aigcfroge อาจใช้ทรัพยากร เช่น ผู้ให้บริการ LLM หรือไม่

---

## การกำหนดค่า

คำสั่งนโยบายแต่ละข้อมีสามฟิลด์:

- `effect` - เป็น `"allow"` หรือ `"deny"`
- `action` - การดำเนินการที่ถูกควบคุม
- `resource` - ID ทรัพยากรหรือรูปแบบไวด์การ์ดที่คำสั่งใช้กับ

ตัวอย่างเช่น ปฏิเสธการใช้ผู้ให้บริการ `openai`:

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "experimental": {
    "policies": [
      {
        "effect": "deny",
        "action": "provider.use",
        "resource": "openai"
      }
    ]
  }
}
```

ผู้ให้บริการที่ถูกปฏิเสธโดยนโยบายจะไม่พร้อมใช้งานสำหรับการเลือกรุ่นหรือการใช้รุ่น แม้ว่าจะมีข้อมูลประจำตัวหรือกำหนดค่าอย่างถูกต้องก็ตาม

---

## นโยบายที่มี

Aigcfroge รองรับการดำเนินการนโยบายหนึ่งรายการในขณะนี้:

| การดำเนินการ | ทรัพยากร | คำอธิบาย |
| ------------ | ---------------- | ----------------------- |
| `provider.use` | รหัสผู้ให้บริการ เช่น `openai` | อนุญาตหรือปฏิเสธการใช้ผู้ให้บริการ LLM |

อาจมีการเพิ่มการดำเนินการนโยบายเพิ่มเติมในอนาคต

---

## การจับคู่

ฟิลด์ `resource` รองรับการจับคู่ไวด์การ์ด ใช้ `*` เพื่อจับคู่อักขระใดๆ ตั้งแต่ศูนย์ขึ้นไป และ `?` เพื่อจับคู่อักขระหนึ่งตัว

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "experimental": {
    "policies": [
      {
        "effect": "deny",
        "action": "provider.use",
        "resource": "company-*"
      }
    ]
  }
}
```

สิ่งนี้ปฏิเสธผู้ให้บริการ เช่น `company-us` และ `company-eu`

## ลำดับของกฎ

เมื่อหลายคำสั่งตรงกัน คำสั่งที่ตรงกันล่าสุดจะชนะ วางกฎกว้างๆ ไว้ก่อน แล้วจึงวางข้อยกเว้นที่เฉพาะเจาะจงมากขึ้นตามหลัง

ตัวอย่างเช่น อนุญาตเฉพาะ Anthropic:

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "experimental": {
    "policies": [
      {
        "effect": "deny",
        "action": "provider.use",
        "resource": "*"
      },
      {
        "effect": "allow",
        "action": "provider.use",
        "resource": "anthropic"
      }
    ]
  }
}
```

หากไม่มีนโยบายใดตรงกับผู้ให้บริการ การใช้ผู้ให้บริการจะถูกอนุญาตตามค่าเริ่มต้น

นโยบายสามารถตั้งค่าได้ทั้งในการกำหนดค่าส่วนกลางและการกำหนดค่าโปรเจ็กต์ของคุณ หากนโยบายจากทั้งสองตำแหน่งตรงกับผู้ให้บริการเดียวกัน นโยบายส่วนกลางของคุณจะมีความสำคัญกว่านโยบายโปรเจ็กต์ สิ่งนี้ป้องกันไม่ให้พื้นที่เก็บข้อมูลเปิดใช้ผู้ให้บริการที่คุณปฏิเสธในระดับส่วนกลางอีกครั้ง

## รายการผู้ให้บริการ

ใช้นโยบายแทนการตั้งค่า `disabled_providers` และ `enabled_providers` แบบเดิมเมื่อควบคุมการเข้าถึงผู้ให้บริการ

เพื่อแทนที่ `disabled_providers`:

```json title="aigcfroge.json"
{
  "experimental": {
    "policies": [
      { "effect": "deny", "action": "provider.use", "resource": "openai" },
      { "effect": "deny", "action": "provider.use", "resource": "google" }
    ]
  }
}
```

เพื่อแทนที่ `enabled_providers` ให้ปฏิเสธผู้ให้บริการทั้งหมดก่อน จากนั้นจึงอนุญาตผู้ให้บริการที่เลือกไว้ตามหลัง:

```json title="aigcfroge.json"
{
  "experimental": {
    "policies": [
      { "effect": "deny", "action": "provider.use", "resource": "*" },
      { "effect": "allow", "action": "provider.use", "resource": "anthropic" },
      { "effect": "allow", "action": "provider.use", "resource": "openai" }
    ]
  }
}
```
