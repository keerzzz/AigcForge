ข้อมูลอ้างอิงทำให้ Aigcfroge เข้าถึงไดเร็กทอรีภายนอกโปรเจ็กต์ปัจจุบันได้ ใช้เพื่อทำให้เอกสาร ไลบรารีที่ใช้ร่วมกัน ตัวอย่าง หรือพื้นที่เก็บข้อมูลอื่นพร้อมใช้งานในขณะที่คุณทำงาน

ข้อมูลอ้างอิงถูกกำหนดค่าด้วยชื่อแทน (alias) ใน `aigcfroge.json` หรือ `aigcfroge.jsonc`

```jsonc title="aigcfroge.jsonc"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "references": {
    "docs": {
      "path": "../product-docs",
      "description": "Use for product behavior and documentation conventions",
    },
    "sdk": {
      "repository": "keerzzz/AigcForge-sdk-js",
      "branch": "main",
      "description": "Use for JavaScript SDK implementation details",
    },
  },
}
```

---

## ไดเรกทอรีในเครื่อง

ใช้ `path` เพื่ออ้างอิงไดเร็กทอรีในเครื่อง

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "docs": {
      "path": "../docs",
    },
  },
}
```

เส้นทางสามารถเป็นได้:

- สัมพันธ์กับไฟล์กำหนดค่าที่กำหนดข้อมูลอ้างอิง
- แบบสัมบูรณ์ เช่น `/home/user/docs`
- สัมพันธ์กับโฮมไดเร็กตอรี่ของคุณ เช่น `~/docs`

คุณยังสามารถใช้สัญกรณ์ย่อแบบสตริงได้:

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "docs": "../docs",
  },
}
```

---

## พื้นที่เก็บข้อมูล Git

ใช้ `repository` เพื่ออ้างอิงพื้นที่เก็บข้อมูล Git Aigcfroge สร้างพื้นที่เก็บข้อมูลในแคชพื้นที่เก็บข้อมูลในเครื่องและทำให้ซอร์สโค้ดที่เช็คเอาท์พร้อมใช้งานเป็นไดเร็กทอรีข้อมูลอ้างอิง

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "effect": {
      "repository": "Effect-TS/effect",
      "branch": "main",
    },
  },
}
```

`repository` ยอมรับ URL ของ Git การอ้างอิงโฮสต์/เส้นทาง และสัญกรณ์ย่อ `owner/repo` ของ GitHub ฟิลด์ `branch` ที่เป็นทางเลือกจะเลือกสาขาหรือ ref หากไม่มี `branch` Aigcfroge จะใช้สาขาเริ่มต้นของพื้นที่เก็บข้อมูล

คุณสามารถใช้สัญกรณ์ย่อแบบสตริงได้เมื่อคุณไม่ต้องการสาขา คำอธิบาย หรือตัวเลือกอื่นๆ:

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "effect": "Effect-TS/effect",
  },
}
```

:::note
ข้อมูลอ้างอิง Git จะถูกรีเฟรชแบบอะซิงโครนัส พื้นที่เก็บข้อมูลที่กำหนดค่าใหม่ใหม่อาจใช้เวลาสักครู่ในการโคลนหรืออัปเดตให้เสร็จสิ้น
:::

## อธิบายการใช้งาน

เพิ่ม `description` เพื่ออธิบายว่าเอเจนต์ควรใช้ข้อมูลอ้างอิงเมื่อใด

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "design-system": {
      "path": "../design-system",
      "description": "Use when implementing UI components or design tokens",
    },
  },
}
```

Aigcfroge รวมข้อมูลอ้างอิงพร้อมคำอธิบายไว้ในบริบทของเอเจนต์ คำอธิบายควรสั้นและเฉพาะเจาะจงพอที่จะแยกแยะข้อมูลอ้างอิงที่มีเนื้อหาคล้ายกันได้ ข้อมูลอ้างอิงที่ไม่มีคำอธิบายยังคงพร้อมใช้งานผ่านการเติมข้อความอัตโนมัติและการใช้งานโดยตรง แต่จะไม่ถูกโฆษณาให้เอเจนต์ทราบ

---

## ซ่อนรายการเติมข้อความอัตโนมัติ

ตั้งค่า `hidden` เป็น `true` เพื่อละเว้นข้อมูลอ้างอิงจากการเติมข้อความอัตโนมัติ `@` ใน TUI

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "internal": {
      "path": "../internal",
      "description": "Use for internal implementation details",
      "hidden": true,
    },
  },
}
```

`hidden` ส่งผลต่อการเติมข้อความอัตโนมัติเท่านั้น ข้อมูลอ้างอิงที่ซ่อนไว้ซึ่งมีคำอธิบายจะยังคงรวมอยู่ในบริบทของเอเจนต์

---

## ใช้ข้อมูลอ้างอิง

ข้อมูลอ้างอิงที่กำหนดค่าจะปรากฏในการเติมข้อความอัตโนมัติ `@` ของ TUI พิมพ์ `@alias` เพื่อแนบรากของข้อมูลอ้างอิง หรือพิมพ์ `@alias/` เพื่อค้นหาไฟล์ภายในนั้น

```text
Compare this implementation with @sdk/src/client.ts
```

เอเจนต์ยังได้รับเส้นทางและคำอธิบายที่แก้ไขแล้วของข้อมูลอ้างอิงที่กำหนดค่าซึ่งมีคำอธิบายในบริบทของระบบ เพื่อให้สามารถตรวจสอบข้อมูลอ้างอิงได้เมื่อเกี่ยวข้องโดยไม่ต้องแนบด้วยตนเอง

Aigcfroge อนุญาตไดเร็กทอรีข้อมูลอ้างอิงผ่านขอบเขตสิทธิ์ไดเรกทอรีภายนอกโดยอัตโนมัติ สิทธิ์เครื่องมือปกติยังคงใช้อยู่ ตัวอย่างเช่น เอเจนต์ที่ไม่สามารถแก้ไขไฟล์จะไม่ได้รับสิทธิ์ในการแก้ไขเพียงเพราะไดเร็กทอรีถูกกำหนดค่าเป็นข้อมูลอ้างอิง

## ฟิลด์การกำหนดค่า

| ฟิลด์         | ในเครื่อง | Git | คำอธิบาย                                      |
| ------------- | ----- | --- | ------------------------------------------------ |
| `path`        | ใช่   | ไม่  | ไดเร็กทอรีข้อมูลอ้างอิงในเครื่อง                  |
| `repository`  | ไม่   | ใช่ | URL ของ Git โฮสต์/เส้นทาง หรือค่า `owner/repo` ของ GitHub |
| `branch`      | ไม่   | ใช่ | สาขา Git หรือ ref ที่เป็นทางเลือก                |
| `description` | ใช่   | ใช่ | คำแนะนำที่อธิบายว่าเมื่อใดควรใช้ข้อมูลอ้างอิง     |
| `hidden`      | ใช่   | ใช่ | ซ่อนข้อมูลอ้างอิงจากการเติมข้อความอัตโนมัติ `@` ของ TUI |

ชื่อแทนของข้อมูลอ้างอิงไม่สามารถว่างเปล่าหรือมี `/` ช่องว่าง backtick หรือเครื่องหมายจุลภาค
