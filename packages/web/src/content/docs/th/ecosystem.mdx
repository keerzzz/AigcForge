:::

คุณยังสามารถลองดู [awesome-aigcfroge](https://github.com/awesome-aigcfroge/awesome-aigcfroge) และ [aigcfroge.cafe](https://aigcfroge.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
