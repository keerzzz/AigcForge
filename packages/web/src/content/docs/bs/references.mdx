Reference daju Aigcfroge pristup direktorijima izvan trenutnog projekta. Koristite ih da dokumentaciju, zajedničke biblioteke, primjere ili drugi repozitorij učinite dostupnim dok radite.

Reference se konfiguriraju pomoću aliasa u `aigcfroge.json` ili `aigcfroge.jsonc`.

```jsonc title="aigcfroge.jsonc"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "references": {
    "docs": {
      "path": "../product-docs",
      "description": "Use for product behavior and documentation conventions",
    },
    "sdk": {
      "repository": "keerzzz/AigcForge-sdk-js",
      "branch": "main",
      "description": "Use for JavaScript SDK implementation details",
    },
  },
}
```

---

## Lokalni direktoriji

Koristite `path` da referencirate lokalni direktorij.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "docs": {
      "path": "../docs",
    },
  },
}
```

Putanje mogu biti:

- U odnosu na konfiguracijski fajl koji definira referencu
- Apsolutne, kao što je `/home/user/docs`
- U odnosu na vaš početni direktorij, kao što je `~/docs`

Također možete koristiti skraćenicu (string):

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "docs": "../docs",
  },
}
```

## Git repozitoriji

Koristite `repository` da referencirate Git repozitorij. Aigcfroge materijalizira repozitorij u svom lokalnom kešu repozitorija i čini izdvojeni izvor dostupnim kao referentni direktorij.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "effect": {
      "repository": "Effect-TS/effect",
      "branch": "main",
    },
  },
}
```

`repository` prihvata Git URL-ove, host/putanje reference i GitHub `owner/repo` skraćenicu. Opcionalno polje `branch` bira granu ili ref. Bez `branch`, Aigcfroge koristi zadanu granu repozitorija.

Možete koristiti skraćenicu (string) kada vam nije potrebna grana, opis ili druge opcije:

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "effect": "Effect-TS/effect",
  },
}
```

:::note
Git reference se osvježavaju asinhrono. Novokonfigurirani repozitorij može trebati trenutak da završi kloniranje ili ažuriranje.
:::

## Opišite upotrebu

Dodajte `description` da objasnite kada agent treba koristiti referencu.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "design-system": {
      "path": "../design-system",
      "description": "Use when implementing UI components or design tokens",
    },
  },
}
```

Aigcfroge uključuje reference s opisima u kontekst agenta. Opisi trebaju biti kratki i dovoljno specifični da razlikuju reference sa sličnim sadržajem. Reference bez opisa ostaju dostupne putem autodovršavanja i direktne upotrebe, ali se ne oglašavaju agentima.

## Sakrij unose autodovršavanja

Postavite `hidden` na `true` da izostavite referencu iz `@` autodovršavanja u TUI-u.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "internal": {
      "path": "../internal",
      "description": "Use for internal implementation details",
      "hidden": true,
    },
  },
}
```

`hidden` utiče samo na autodovršavanje. Skrivena referenca s opisom ostaje uključena u kontekst agenta.

---

## Korištenje referenci

Konfigurirane reference se pojavljuju u TUI `@` autodovršavanju. Ukucajte `@alias` da prikačite korijen reference, ili `@alias/` da pretražujete datoteke unutar njega.

```text
Compare this implementation with @sdk/src/client.ts
```

Agenti također primaju razriješene putanje i opise konfiguriranih referenci koje imaju opise u svom sistemskom kontekstu, tako da mogu pregledati referencu kada je relevantna bez da je ručno prikačite.

Aigcfroge automatski dozvoljava referentne direktorije kroz svoju granicu dozvola za vanjske direktorije. Uobičajene dozvole alata se i dalje primjenjuju; na primjer, agent koji ne može uređivati datoteke ne dobija pristup uređivanju zato što je direktorij konfiguriran kao referenca.

## Konfiguracijska polja

| Polje          | Lokalno | Git | Opis                                       |
| -------------- | ------- | --- | ------------------------------------------ |
| `path`         | Da      | Ne  | Lokalni referentni direktorij              |
| `repository`   | Ne      | Da  | Git URL, host/putanja ili GitHub `owner/repo` vrijednost |
| `branch`       | Ne      | Da  | Opcionalna Git grana ili ref               |
| `description`  | Da      | Da  | Smjernice koje opisuju kada koristiti referencu |
| `hidden`       | Da      | Da  | Sakrij referencu iz TUI `@` autodovršavanja |

Aliasi referenci ne mogu biti prazni niti sadržavati `/`, razmake, backtick ili zareze.
