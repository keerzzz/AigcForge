---
title: Politike
description: Kontrolirajte koje konfigurirane resurse Aigcfroge može koristiti.
---

Politike kontroliraju da li Aigcfroge smije izvršiti radnju na imenovanom resursu. Ova funkcija je eksperimentalna i konfigurira se pomoću `experimental.policies` niza u `aigcfroge.json`.

Politike su odvojene od [dozvola](/docs/permissions). Dozvole kontroliraju šta alati mogu raditi tokom sesije, dok politike kontroliraju da li Aigcfroge smije koristiti resurs kao što je LLM provajder.

---

## Konfiguracija

Svaka izjava politike ima tri polja:

- `effect` - Ili `"allow"` ili `"deny"`.
- `action` - Operacija koja se kontrolira.
- `resource` - ID resursa ili zamjenski uzorak na koji se izjava odnosi.

Na primjer, zabranite korištenje `openai` provajdera:

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "experimental": {
    "policies": [
      {
        "effect": "deny",
        "action": "provider.use",
        "resource": "openai"
      }
    ]
  }
}
```

Provajder zabranjen politikom nije dostupan za odabir modela ili korištenje modela, čak i ako ima vjerodajnice ili je inače ispravno konfiguriran.

---

## Dostupne politike

Aigcfroge trenutno podržava jednu radnju politike:

| Radnja          | Resurs                            | Opis                                     |
| --------------- | --------------------------------- | ---------------------------------------- |
| `provider.use`  | ID provajdera, kao što je `openai` | Dozvoli ili zabrani korištenje LLM provajdera. |

Više radnji politike može biti dodano u budućnosti.

---

## Podudaranje

Polje `resource` podržava podudaranje zamjenskih znakova. Koristite `*` da podudarite nula ili više znakova i `?` da podudarite jedan znak.

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "experimental": {
    "policies": [
      {
        "effect": "deny",
        "action": "provider.use",
        "resource": "company-*"
      }
    ]
  }
}
```

Ovo zabranjuje provajdere kao što su `company-us` i `company-eu`.

---

## Redoslijed pravila

Kada se podudara više izjava, posljednja podudarajuća izjava pobjeđuje. Stavite široka pravila prvo, a zatim konkretnije izuzetke poslije njih.

Na primjer, dozvolite samo Anthropic:

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "experimental": {
    "policies": [
      {
        "effect": "deny",
        "action": "provider.use",
        "resource": "*"
      },
      {
        "effect": "allow",
        "action": "provider.use",
        "resource": "anthropic"
      }
    ]
  }
}
```

Ako se nijedna politika ne podudara s provajderom, korištenje provajdera je dozvoljeno prema zadanim postavkama.

Politike se mogu postaviti i u vašoj globalnoj konfiguraciji i u konfiguraciji projekta. Ako se politike iz obje lokacije podudaraju s istim provajderom, vaša globalna politika ima prednost nad politikom projekta. Ovo sprječava repozitorij da ponovo omogući provajdera kojeg ste globalno zabranili.

---

## Liste provajdera

Koristite politike umjesto starijih postavki `disabled_providers` i `enabled_providers` kada kontrolirate pristup provajderima.

Da zamijenite `disabled_providers`:

```json title="aigcfroge.json"
{
  "experimental": {
    "policies": [
      { "effect": "deny", "action": "provider.use", "resource": "openai" },
      { "effect": "deny", "action": "provider.use", "resource": "google" }
    ]
  }
}
```

Da zamijenite `enabled_providers`, prvo zabranite sve provajdere, a zatim dozvolite odabrane provajdere:

```json title="aigcfroge.json"
{
  "experimental": {
    "policies": [
      { "effect": "deny", "action": "provider.use", "resource": "*" },
      { "effect": "allow", "action": "provider.use", "resource": "anthropic" },
      { "effect": "allow", "action": "provider.use", "resource": "openai" }
    ]
  }
}
```
