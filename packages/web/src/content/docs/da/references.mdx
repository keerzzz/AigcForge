---
title: Referencer
description: Tilføj lokale mapper og Git-repositories som projektreferencer.
---

Referencer giver Aigcfroge adgang til mapper uden for det aktuelle projekt. Brug dem til at gøre dokumentation, delte biblioteker, eksempler eller et andet repository tilgængelige, mens du arbejder.

Referencer konfigureres med et alias i `aigcfroge.json` eller `aigcfroge.jsonc`.

```jsonc title="aigcfroge.jsonc"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "references": {
    "docs": {
      "path": "../product-docs",
      "description": "Use for product behavior and documentation conventions",
    },
    "sdk": {
      "repository": "keerzzz/AigcForge-sdk-js",
      "branch": "main",
      "description": "Use for JavaScript SDK implementation details",
    },
  },
}
```

---

## Lokale mapper

Brug `path` til at referere til en lokal mappe.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "docs": {
      "path": "../docs",
    },
  },
}
```

Stier kan være:

- Relative i forhold til den konfigurationsfil, der definerer referencen
- Absolutte, såsom `/home/user/docs`
- Relative i forhold til din hjemmemappe, såsom `~/docs`

Du kan også bruge en streng-forkortelse:

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "docs": "../docs",
  },
}
```

## Git-repositories

Brug `repository` til at referere til et Git-repository. Aigcfroge materialiserer repository'et i sin lokale repository-cache og gør den tjekkede kildekode tilgængelig som en referencemappe.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "effect": {
      "repository": "Effect-TS/effect",
      "branch": "main",
    },
  },
}
```

`repository` accepterer Git-URL'er, vært/sti-referencer og GitHub `owner/repo`-forkortelser. Det valgfrie felt `branch` vælger en branch eller ref. Uden `branch` bruger Aigcfroge repository'ets standardbranch.

Du kan bruge streng-forkortelse, når du ikke har brug for en branch, beskrivelse eller andre muligheder:

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "effect": "Effect-TS/effect",
  },
}
```

:::note
Git-referencer opdateres asynkront. Et nyligt konfigureret repository kan tage et øjeblik om at færdiggøre kloning eller opdatering.
:::

## Beskriv brug

Tilføj `description` for at forklare, hvornår en agent bør bruge en reference.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "design-system": {
      "path": "../design-system",
      "description": "Use when implementing UI components or design tokens",
    },
  },
}
```

Aigcfroge inkluderer referencer med beskrivelser i agentkonteksten. Beskrivelser bør være korte og specifikke nok til at skelne referencer med lignende indhold. Referencer uden beskrivelser forbliver tilgængelige via autofuldførelse og direkte brug, men annonceres ikke til agenter.

---

## Skjul autofuldførelsesposter

Angiv `hidden` som `true` for at udelade en reference fra `@`-autofuldførelsen i TUI'et.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "internal": {
      "path": "../internal",
      "description": "Use for internal implementation details",
      "hidden": true,
    },
  },
}
```

`hidden` påvirker kun autofuldførelse. En skjult reference med en beskrivelse forbliver inkluderet i agentkonteksten.

---

## Brug referencer

Konfigurerede referencer vises i TUI'ets `@`-autofuldførelse. Skriv `@alias` for at tilknytte referenceroden eller `@alias/` for at søge efter filer i den.

```text
Compare this implementation with @sdk/src/client.ts
```

Agenter modtager også de opløste stier og beskrivelser af de konfigurerede referencer, der har beskrivelser i deres systemkontekst, så de kan inspicere en reference, når den er relevant, uden at du tilknytter den manuelt.

Aigcfroge tillader automatisk referencemapper gennem sin grænse for eksterne mapper. Normale værktøjstilladelser gælder stadig; for eksempel får en agent, der ikke kan redigere filer, ikke redigeringsadgang, bare fordi en mappe er konfigureret som en reference.

## Konfigurer felter

| Felt          | Lokal | Git | Beskrivelse                                          |
| ------------- | ----- | --- | ---------------------------------------------------- |
| `path`        | Ja    | Nej | Lokal referencemappe                                 |
| `repository`  | Nej   | Ja  | Git-URL, vært/sti eller GitHub `owner/repo`-værdi    |
| `branch`      | Nej   | Ja  | Valgfri Git-branch eller ref                         |
| `description` | Ja    | Ja  | Vejledning, der beskriver, hvornår referencen bruges |
| `hidden`      | Ja    | Ja  | Skjul referencen fra TUI'ets `@`-autofuldførelse     |

Reference-aliaser kan ikke være tomme eller indeholde `/`, mellemrum, backticks eller kommaer.
