---
title: リファレンス
description: ローカルディレクトリと Git リポジトリをプロジェクトリファレンスとして追加します。
---

リファレンスは、現在のプロジェクト外のディレクトリへの Aigcfroge のアクセスを提供します。作業中にドキュメント、共有ライブラリ、サンプル、または別のリポジトリを利用できるようにするために使用します。

リファレンスは、`aigcfroge.json` または `aigcfroge.jsonc` でエイリアスによって設定されます。

```jsonc title="aigcfroge.jsonc"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "references": {
    "docs": {
      "path": "../product-docs",
      "description": "Use for product behavior and documentation conventions",
    },
    "sdk": {
      "repository": "keerzzz/AigcForge-sdk-js",
      "branch": "main",
      "description": "Use for JavaScript SDK implementation details",
    },
  },
}
```

---

## ローカルディレクトリ

`path` を使用してローカルディレクトリを参照します。

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "docs": {
      "path": "../docs",
    },
  },
}
```

パスは次のとおりです。

- リファレンスを定義する設定ファイルからの相対パス
- `/home/user/docs` などの絶対パス
- `~/docs` などのホームディレクトリからの相対パス

文字列のショートハンドも使用できます。

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "docs": "../docs",
  },
}
```

---

## Git リポジトリ

`repository` を使用して Git リポジトリを参照します。Aigcfroge はリポジトリをローカルリポジトリキャッシュに実体化し、チェックアウトされたソースをリファレンスディレクトリとして利用できるようにします。

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "effect": {
      "repository": "Effect-TS/effect",
      "branch": "main",
    },
  },
}
```

`repository` は、Git URL、ホスト/パス参照、および GitHub の `owner/repo` ショートハンドを受け入れます。オプションの `branch` フィールドは、ブランチまたは ref を選択します。`branch` がない場合、Aigcfroge はリポジトリのデフォルトブランチを使用します。

ブランチ、説明、その他のオプションが不要な場合は、文字列のショートハンドを使用できます。

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "effect": "Effect-TS/effect",
  },
}
```

:::note
Git リファレンスは非同期で更新されます。新しく設定したリポジトリは、クローンまたは更新が完了するまでに少し時間がかかる場合があります。
:::

## 使用法の説明

エージェントがリファレンスをいつ使用すべきかを説明するには、`description` を追加します。

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "design-system": {
      "path": "../design-system",
      "description": "Use when implementing UI components or design tokens",
    },
  },
}
```

Aigcfroge は、説明付きのリファレンスをエージェントのコンテキストに含めます。説明は、類似した内容のリファレンスを区別できるように、短く具体的である必要があります。説明のないリファレンスは、オートコンプリートと直接使用では引き続き利用できますが、エージェントには通知されません。

---

## オートコンプリートエントリを非表示にする

`hidden` を `true` に設定すると、TUI の `@` オートコンプリートからリファレンスを除外できます。

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "internal": {
      "path": "../internal",
      "description": "Use for internal implementation details",
      "hidden": true,
    },
  },
}
```

`hidden` はオートコンプリートのみに影響します。説明付きの非表示リファレンスは、エージェントのコンテキストに引き続き含まれます。

---

## リファレンスの使用

設定されたリファレンスは、TUI の `@` オートコンプリートに表示されます。`@alias` と入力してリファレンスのルートを添付するか、`@alias/` と入力して内部のファイルを検索します。

```text
Compare this implementation with @sdk/src/client.ts
```

エージェントは、システムコンテキスト内で説明を持つ設定済みリファレンスの解決されたパスと説明も受け取るため、手動で添付しなくても、関連するときにリファレンスを調査できます。

Aigcfroge は、外部ディレクトリの権限境界を通じてリファレンスディレクトリを自動的に許可します。通常のツール権限は引き続き適用されます。たとえば、ファイルを編集できないエージェントは、ディレクトリがリファレンスとして設定されているからといって編集アクセス権を取得することはありません。

## フィールドの設定

| フィールド   | ローカル | Git | 説明                                              |
| ------------ | ------- | --- | ------------------------------------------------- |
| `path`       | はい    | いいえ | ローカルリファレンスディレクトリ                  |
| `repository` | いいえ  | はい | Git URL、ホスト/パス、または GitHub の `owner/repo` 値 |
| `branch`     | いいえ  | はい | オプションの Git ブランチまたは ref                |
| `description`| はい    | はい | リファレンスをいつ使用するかを説明するガイダンス  |
| `hidden`     | はい    | はい | TUI の `@` オートコンプリートからリファレンスを非表示にします |

リファレンスのエイリアスは空にできず、`/`、空白、バッククォート、またはカンマを含めることはできません。
