title: IDE
description: Розширення Aigcfroge для VS Code, Cursor та інших IDE
---

Aigcfroge інтегрується з VS Code, Cursor або будь-якою IDE, яка підтримує термінал. Просто виконайте `aigcfroge` у терміналі, щоб почати.

---

## Використання

- **Швидкий запуск**: Використовуйте `Cmd+Esc` (Mac) або `Ctrl+Esc` (Windows/Linux), щоб відкрити Aigcfroge у розділеному перегляді термінала, або сфокусувати наявну сесію термінала, якщо вона вже запущена.
- **Нова сесія**: Використовуйте `Cmd+Shift+Esc` (Mac) або `Ctrl+Shift+Esc` (Windows/Linux), щоб почати нову сесію термінала Aigcfroge, навіть якщо одна вже відкрита. Ви також можете натиснути кнопку Aigcfroge в інтерфейсі.
- **Усвідомлення контексту**: автоматично діліться з Aigcfroge вашим поточним виділенням або вкладкою.
- **Скорочення посилань на файли**: Використовуйте `Cmd+Option+K` (Mac) або `Alt+Ctrl+K` (Linux/Windows), щоб вставити посилання на файли. Наприклад, `@File#L37-42`.

---

## Встановлення

Щоб установити Aigcfroge у VS Code та популярні форки, як-от Cursor, Windsurf, VSCodium:

1. Відкрийте VS Code
2. Відкрийте інтегрований термінал
3. Виконайте `aigcfroge` — розширення встановлюється автоматично

Якщо ж ви хочете використовувати власну IDE, коли виконуєте `/editor` або `/export` із TUI, вам потрібно встановити `export EDITOR="code --wait"`. [Дізнайтеся більше](/docs/tui/#editor-setup).

---

### Ручне встановлення

Знайдіть **Aigcfroge** у маркетплейсі розширень і натисніть **Установити**.

---

### Усунення неполадок

Якщо розширення не вдається встановити автоматично:

- Переконайтеся, що ви запускаєте `aigcfroge` в інтегрованому терміналі.
- Переконайтеся, що CLI для вашої IDE встановлено:
  - Для VS Code: команда `code`
  - Для Cursor: команда `cursor`
  - Для Windsurf: команда `windsurf`
  - Для VSCodium: команда `codium`
  - Якщо ні, виконайте `Cmd+Shift+P` (Mac) або `Ctrl+Shift+P` (Windows/Linux) і знайдіть "Shell Command: Install 'code' command in PATH" (або еквівалент для вашої IDE)
- Переконайтеся, що VS Code має дозвіл на встановлення розширень
