Aigcfroge надає інтерактивний термінальний інтерфейс (TUI) для роботи з вашими проєктами за допомогою LLM.

Запуск Aigcfroge відкриває TUI для поточного каталогу.

```bash
aigcfroge
```

Або ви можете запустити його для певного робочого каталогу.

```bash
aigcfroge /path/to/project
```

Перебуваючи в TUI, ви можете звертатися до нього з повідомленням.

```text
Give me a quick summary of the codebase.
```

## Посилання на файли

Ви можете посилатися на файли у своїх повідомленнях за допомогою `@`. Це виконує нечіткий пошук файлів у поточному робочому каталозі.

:::tip
Також ви можете використовувати `@`, щоб посилатися на файли у своїх повідомленнях.
:::

```text "@packages/functions/src/api/index.ts"
How is auth handled in @packages/functions/src/api/index.ts?
```

Вміст файлу автоматично додається до розмови.

Налаштовані [посилання](/docs/references) також з'являються в автодоповненні `@`. Введіть `@alias`, щоб додати корінь посилання як контекст, або введіть `@alias/`, щоб автодоповнити файли всередині цього посилання.

```text "@docs/README.md"
Compare our setup with @docs/README.md
```

## Команди Bash

Почніть повідомлення з `!`, щоб виконати команду оболонки.

```bash frame="none"
!ls -la
```

Вивід команди додається до розмови як результат інструмента.

## Команди

Під час використання Aigcfroge TUI ви можете ввести `/`, після якого вказати назву команди, щоб швидко виконувати дії. Наприклад:

```bash frame="none"
/help
```

Більшість команд також мають клавіатурні скорочення з `ctrl+x` як клавішею-лідером за замовчуванням. [Дізнайтеся більше](/docs/keybinds).

Ось усі доступні slash-команди:

---

### connect

Додає провайдера до Aigcfroge. Дозволяє вибрати серед доступних провайдерів і додати їхні API-ключі.

```bash frame="none"
/connect
```

---

### compact

Ущільнює поточну сесію. _Псевдонім_: `/summarize`

```bash frame="none"
/compact
```

**Клавіші:** `ctrl+x c`

---

### details

Перемикає відображення деталей виконання інструментів.

```bash frame="none"
/details
```

---

### editor

Відкриває зовнішній редактор для написання повідомлень. Використовує редактор, встановлений у змінній середовища `EDITOR`. [Дізнайтеся більше](#editor-setup).

```bash frame="none"
/editor
```

**Клавіші:** `ctrl+x e`

---

### exit

Виходить з Aigcfroge. _Псевдоніми_: `/quit`, `/q`

```bash frame="none"
/exit
```

**Клавіші:** `ctrl+x q`

---

### export

Експортує поточну розмову у Markdown і відкриває у вашому редакторі за замовчуванням. Використовує редактор, встановлений у змінній середовища `EDITOR`. [Дізнайтеся більше](#editor-setup).

```bash frame="none"
/export
```

**Клавіші:** `ctrl+x x`

---

### help

Показує діалогове вікно довідки.

```bash frame="none"
/help
```

---

### init

Покрокове налаштування для створення або оновлення `AGENTS.md`. [Дізнайтеся більше](/docs/rules).

```bash frame="none"
/init
```

---

### models

Список доступних моделей.

```bash frame="none"
/models
```

**Клавіші:** `ctrl+x m`

---

### new

Починає нову сесію. _Псевдонім_: `/clear`

```bash frame="none"
/new
```

**Клавіші:** `ctrl+x n`

---

### redo

Повторює раніше скасоване повідомлення. Доступно лише після використання `/undo`.

:::tip
Будь-які зміни файлів також буде відновлено.
:::

Внутрішньо для керування змінами файлів використовується Git. Тож ваш проєкт **має
бути Git-репозиторієм**.

```bash frame="none"
/redo
```

**Клавіші:** `ctrl+x r`

---

### sessions

Список сесій і перемикання між ними. _Псевдоніми_: `/resume`, `/continue`

```bash frame="none"
/sessions
```

**Клавіші:** `ctrl+x l`

---

### share

Поширити поточну сесію. [Дізнайтеся більше](/docs/share).

```bash frame="none"
/share
```

---

### themes

Список доступних тем.

```bash frame="none"
/themes
```

**Клавіші:** `ctrl+x t`

---

### thinking

Перемикає відображення блоків роздумів/міркувань у розмові. Коли ввімкнено, ви можете бачити процес міркування моделі для моделей, які підтримують розширені роздуми.

:::note
Ця команда лише керує тим, чи **відображаються** блоки роздумів — вона не вмикає та не вимикає здатність моделі до міркування. Щоб перемикати власне здатність до міркування, використовуйте `ctrl+t`, щоб перемикатися між варіантами моделі.
:::

```bash frame="none"
/thinking
```

---

### undo

Скасовує останнє повідомлення в розмові. Видаляє найостанніше повідомлення користувача, усі наступні відповіді та будь-які зміни файлів.

:::tip
Будь-які внесені зміни файлів також буде скасовано.
:::

Внутрішньо для керування змінами файлів використовується Git. Тож ваш проєкт **має
бути Git-репозиторієм**.

```bash frame="none"
/undo
```

**Клавіші:** `ctrl+x u`

---

### unshare

Припинити поширення поточної сесії. [Дізнайтеся більше](/docs/share#un-sharing).

```bash frame="none"
/unshare
```

## Налаштування редактора

І команда `/editor`, і команда `/export` використовують редактор, указаний у вашій змінній середовища `EDITOR`.

<Tabs>
  <TabItem label="Linux/macOS">
    ```bash
    # Example for nano or vim
    export EDITOR=nano
    export EDITOR=vim

    # For GUI editors, VS Code, Cursor, VSCodium, Windsurf, Zed, etc.
    # include --wait
    export EDITOR="code --wait"
    ```

    Щоб зробити це постійним, додайте це до свого профілю оболонки:
    `~/.bashrc`, `~/.zshrc` тощо.

  </TabItem>

  <TabItem label="Windows (CMD)">
    ```bash
    set EDITOR=notepad

    # For GUI editors, VS Code, Cursor, VSCodium, Windsurf, Zed, etc.
    # include --wait
    set EDITOR=code --wait
    ```

    Щоб зробити це постійним, скористайтеся **Властивостями системи** > **Змінними
    середовища**.

  </TabItem>

  <TabItem label="Windows (PowerShell)">
    ```powershell
    $env:EDITOR = "notepad"

    # For GUI editors, VS Code, Cursor, VSCodium, Windsurf, Zed, etc.
    # include --wait
    $env:EDITOR = "code --wait"
    ```

    Щоб зробити це постійним, додайте це до свого профілю PowerShell.

  </TabItem>
</Tabs>

Популярні варіанти редакторів:

- `code` — Visual Studio Code
- `cursor` — Cursor
- `windsurf` — Windsurf
- `nvim` — редактор Neovim
- `vim` — редактор Vim
- `nano` — редактор Nano
- `notepad` — Блокнот Windows
- `subl` — Sublime Text

:::note
Деякі редактори, як-от VS Code, потрібно запускати з прапорцем `--wait`.
:::

Деяким редакторам потрібні аргументи командного рядка для запуску в блокуючому режимі. Прапорець `--wait` змушує процес редактора блокуватися, доки його не закриють.

## Конфігурація

Ви можете налаштовувати поведінку TUI через `tui.json` (або `tui.jsonc`).

```json title="tui.json"
{
  "$schema": "https://aigcfroge.ai/tui.json",
  "theme": "aigcfroge",
  "leader_timeout": 2000,
  "keybinds": {
    "leader": "ctrl+x",
    "command_list": "ctrl+p"
  },
  "scroll_speed": 3,
  "scroll_acceleration": {
    "enabled": false
  },
  "diff_style": "auto",
  "mouse": true,
  "attention": {
    "enabled": true,
    "notifications": true,
    "sound": true,
    "volume": 0.4,
    "sound_pack": "aigcfroge.default",
    "sounds": {
      "error": "./sounds/error.mp3"
    }
  }
}
```

Це окремо від `aigcfroge.json`, який налаштовує поведінку сервера/середовища виконання.

`keybinds` об'єднується з вбудованими значеннями за замовчуванням, тож вам потрібно налаштувати лише ті скорочення, які ви хочете змінити.

### Параметри

- `theme` — задає тему вашого інтерфейсу. [Дізнайтеся більше](/docs/themes).
- `keybinds` — налаштовує клавіатурні скорочення. [Дізнайтеся більше](/docs/keybinds).
- `leader_timeout` — визначає, скільки Aigcfroge чекає після натискання клавіші-лідера. За замовчуванням — `2000`.
- `scroll_acceleration.enabled` — увімкнення прискорення прокручування в стилі macOS для плавного, природного прокручування. Коли ввімкнено, швидкість прокручування зростає під час швидких жестів і залишається точною для повільніших рухів. **Це налаштування має перевагу над `scroll_speed` і замінює його, коли ввімкнено.**
- `scroll_speed` — визначає, як швидко прокручується TUI під час використання команд прокручування (мінімум: `0.001`, підтримує десяткові значення). За замовчуванням — `3`. **Примітка: ігнорується, якщо `scroll_acceleration.enabled` встановлено у `true`.**
- `diff_style` — керує відображенням дифів. `"auto"` адаптується до ширини термінала, `"stacked"` завжди показує одноколонкове компонування.
- `mouse` — увімкнення або вимкнення захоплення миші в TUI (за замовчуванням: `true`). Коли вимкнено, зберігається рідна поведінка виділення/прокручування мишею термінала.
- `attention` — налаштовує сповіщення та звуки TUI. Вимкнено за замовчуванням.

Використовуйте `AIGCFROGE_TUI_CONFIG`, щоб завантажити власний шлях до конфігурації TUI.

### Attention

TUI може запитувати увагу для питань, дозволів, помилок сесій і завершених сесій. Увімкніть його за допомогою `attention.enabled`; вбудовані події відтворюють звуки під час спрацювання, а події, не пов'язані з субагентами, запитують сповіщення на робочому столі лише тоді, коли термінал не має фокусу.

- `enabled` — увімкнення всіх сповіщень і звуків уваги. За замовчуванням — `false`.
- `notifications` — дозволяє сповіщення на робочому столі через термінал, коли увагу ввімкнено. За замовчуванням — `true`.
- `sound` — дозволяє звуки уваги, коли увагу ввімкнено. За замовчуванням — `true`.
- `volume` — гучність звуку за замовчуванням від `0` до `1`. За замовчуванням — `0.4`.
- `sound_pack` — ідентифікатор звукового пакета, який слід використовувати. За замовчуванням — `aigcfroge.default`.
- `sounds` — замінює звукові файли для `default`, `question`, `permission`, `error`, `done` або `subagent_done`. Шляхи можуть бути абсолютними, `file://` URL-адресами або відносними до `tui.json`.

## Налаштування інтерфейсу

Ви можете налаштовувати різні аспекти відображення TUI за допомогою палітри команд (`ctrl+p`). Ці налаштування зберігаються після перезапусків.

---

#### Відображення імені користувача

Перемикає, чи ваше ім'я користувача з'являється в повідомленнях чату. Доступ до цього:

- Палітра команд: знайдіть «username» або «hide username»
- Налаштування зберігається автоматично та запам'ятовується між сесіями TUI
