Aigcfroge може форматувати файли після їх створення або редагування за допомогою форматерів, специфічних для мови програмування. Форматери вимкнено за замовчуванням; увімкніть їх у своїй конфігурації, перш ніж Aigcfroge почне їх використовувати.

---

## Вбудовані форматери

Aigcfroge має кілька вбудованих форматерів для популярних мов і фреймворків. Нижче наведено список форматерів, підтримуваних розширень файлів, а також команд або параметрів конфігурації, які їм потрібні.

---

## Як це працює

Коли Aigcfroge записує або редагує файл і форматери увімкнено, він:

1. Перевіряє розширення файлу за всіма увімкненими форматерами.
2. Запускає відповідну команду форматера для файлу.
3. Застосовує зміни форматування.

Цей процес відбувається у фоновому режимі для увімкнених форматерів.

## Налаштування

Ви можете вмикати й налаштовувати форматери через розділ `formatter` у конфігурації Aigcfroge.

Щоб увімкнути всі вбудовані форматери, встановіть `formatter` у `true`.

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "formatter": true
}
```

Використовуйте об'єкт, щоб залишити вбудовані форматери увімкненими, налаштовуючи перевизначення або власні форматери.

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "formatter": {}
}
```

Кожна конфігурація форматера підтримує наступне:

| Властивість   | Тип       | Опис                                                                                             |
| ------------- | --------- | ------------------------------------------------------------------------------------------------ |
| `disabled`    | boolean   | Встановіть це значення на `true`, щоб вимкнути форматер                                         |
| `command`     | string[]  | Команда для запуску форматування. Обов'язкова для власних форматерів; необов'язкова для вбудованих. |
| `environment` | object    | Змінні середовища, які потрібно встановити під час запуску форматера                             |
| `extensions`  | string[]  | Розширення файлів, які має обробляти цей форматер                                                |

Розгляньмо кілька прикладів.

---

### Вимкнення форматерів

Якщо `formatter` не вказано, усі форматери вимкнено. Щоб вимкнути всі форматери після того, як інша конфігурація їх увімкнула, встановіть `formatter` у `false`:

```json title="aigcfroge.json" {3}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "formatter": false
}
```

Щоб вимкнути **конкретний** форматер, встановіть `disabled` у `true`:

```json title="aigcfroge.json" {5}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "formatter": {
    "prettier": {
      "disabled": true
    }
  }
}
```

---

### Власні форматери

Ви можете налаштовувати вбудовані форматери за допомогою таких параметрів, як `environment` або `extensions`. Щоб додати власний форматер, вкажіть `command` та `extensions`:

```json title="aigcfroge.json" {4-14}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "formatter": {
    "prettier": {
      "command": ["npx", "prettier", "--write", "$FILE"],
      "environment": {
        "NODE_ENV": "development"
      },
      "extensions": [".js", ".ts", ".jsx", ".tsx"]
    },
    "custom-markdown-formatter": {
      "command": ["deno", "fmt", "$FILE"],
      "extensions": [".md"]
    }
  }
}
```

**Плейсхолдер `$FILE`** у команді буде замінено на шлях до файлу, який форматується.
