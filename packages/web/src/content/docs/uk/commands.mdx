---
title: Команди

---

Спеціальні команди дозволяють вказати запит, який ви хочете запустити, коли ця команда виконується в TUI.

```bash frame="none"
/my-command
```

Спеціальні команди є доповненням до вбудованих команд, таких як `/init`, `/undo`, `/redo`, `/share`, `/help`. [Дізнатися більше](/docs/tui#commands).

---

## Створення файлів команд

Створюйте файли Markdown у каталозі `commands/`, щоб визначати спеціальні команди.

Створіть `.aigcfroge/commands/test.md`:

```md title=".aigcfroge/commands/test.md"
---
description: Run tests with coverage
agent: build
model: anthropic/claude-3-5-sonnet-20241022
---

Run the full test suite with coverage report and show any failures.
Focus on the failing tests and suggest fixes.
```

Frontmatter визначає властивості команди. Вміст стає шаблоном.

Використовуйте команду, ввівши `/` з наступною назвою команди.

```bash frame="none"
"/test"
```

---

## Конфігурація

Ви можете додавати спеціальні команди через конфігурацію Aigcfroge або створюючи файли Markdown у каталозі `commands/`.

---

### JSON

Використовуйте опцію `command` у [конфігурації](/docs/config) Aigcfroge:

```json title="aigcfroge.jsonc" {4-12}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "command": {
    // This becomes the name of the command
    "test": {
      // This is the prompt that will be sent to the LLM
      "template": "Run the full test suite with coverage report and show any failures.\nFocus on the failing tests and suggest fixes.",
      // This is shown as the description in the TUI
      "description": "Run tests with coverage",
      "agent": "build",
      "model": "anthropic/claude-3-5-sonnet-20241022"
    }
  }
}
```

Тепер ви можете запустити цю команду в TUI:

```bash frame="none"
/test
```

---

### Markdown

Ви також можете визначати команди за допомогою файлів Markdown. Розмістіть їх у:

- Глобально: `~/.config/aigcfroge/commands/`
- Для проєкту: `.aigcfroge/commands/`

```markdown title="~/.config/aigcfroge/commands/test.md"
---
description: Run tests with coverage
agent: build
model: anthropic/claude-3-5-sonnet-20241022
---

Run the full test suite with coverage report and show any failures.
Focus on the failing tests and suggest fixes.
```

Назва файлу Markdown стає назвою команди. Наприклад, `test.md` дозволяє запустити:

```bash frame="none"
/test
```

## Конфігурація запиту

Запити для спеціальних команд підтримують кілька спеціальних заповнювачів і синтаксис.

---

### Аргументи

Передавайте аргументи командам за допомогою заповнювача `$ARGUMENTS`.

```md title=".aigcfroge/commands/component.md"
---
description: Create a new component
---

Create a new React component named $ARGUMENTS with TypeScript support.
Include proper typing and basic structure.
```

Запустіть команду з аргументами:

```bash frame="none"
/component Button
```

І `$ARGUMENTS` буде замінено на `Button`.

Ви також можете отримати доступ до окремих аргументів за допомогою позиційних параметрів:

- `$1` — перший аргумент
- `$2` — другий аргумент
- `$3` — третій аргумент
- І так далі...

Наприклад:

```md title=".aigcfroge/commands/create-file.md"
---
description: Create a new file with content
---

Create a file named $1 in the directory $2
with the following content: $3
```

Запустіть команду:

```bash frame="none"
/create-file config.json src "{ \"key\": \"value\" }"
```

Це замінює:

- `$1` на `config.json`
- `$2` на `src`
- `$3` на `{ "key": "value" }`

---

### Вивід оболонки

Використовуйте _!`command`_, щоб вставити [вивід bash-команди](/docs/tui#bash-commands) у свій запит.

Наприклад, щоб створити спеціальну команду, яка аналізує покриття тестами:

```md title=".aigcfroge/commands/analyze-coverage.md"
---
description: Analyze test coverage
---

Here are the current test results:
!`npm test`

Based on these results, suggest improvements to increase coverage.
```

Або щоб переглянути останні зміни:

```md title=".aigcfroge/commands/review-changes.md"
---
description: Review recent changes
---

Recent git commits:
!`git log --oneline -10`

Review these changes and suggest any improvements.
```

Команди виконуються в кореневому каталозі вашого проєкту, а їхній вивід стає частиною запиту.

---

### Файлові посилання

Включайте файли у свою команду за допомогою `@` із наступною назвою файлу.

```md title=".aigcfroge/commands/review-component.md"
---
description: Review component
---

Review the component in @src/components/Button.tsx.
Check for performance issues and suggest improvements.
```

Вміст файлу автоматично включається в запит.

## Опції

Розгляньмо детально параметри конфігурації.

---

### Шаблон

Опція `template` визначає запит, який буде надіслано LLM під час виконання команди.

```json title="aigcfroge.json"
{
  "command": {
    "test": {
      "template": "Run the full test suite with coverage report and show any failures.\nFocus on the failing tests and suggest fixes."
    }
  }
}
```

Це **обов'язкова** опція конфігурації.

---

### Опис

Використовуйте опцію `description`, щоб надати короткий опис того, що робить команда.

```json title="aigcfroge.json"
{
  "command": {
    "test": {
      "description": "Run tests with coverage"
    }
  }
}
```

Це відображається як опис у TUI, коли ви вводите команду.

---

### Агент

Використовуйте конфігурацію `agent`, щоб за бажанням указати, який [агент](/docs/agents) має виконати цю команду.
Якщо це [субагент](/docs/agents/#subagents), команда за замовчуванням запускатиме виклик субагента.
Щоб вимкнути цю поведінку, встановіть `subtask` у `false`.

```json title="aigcfroge.json"
{
  "command": {
    "review": {
      "agent": "plan"
    }
  }
}
```

Це **необов'язкова** опція конфігурації. Якщо не вказано, за замовчуванням використовується ваш поточний агент.

---

### Підзадача

Використовуйте логічну опцію `subtask`, щоб примусово запускати виклик [субагента](/docs/agents/#subagents) для команди.
Це корисно, якщо ви хочете, щоб команда не забруднювала ваш основний контекст, і **примушує** агента діяти як субагент,
навіть якщо для [агента](/docs/agents) у конфігурації встановлено `mode` у `primary`.

```json title="aigcfroge.json"
{
  "command": {
    "analyze": {
      "subtask": true
    }
  }
}
```

Це **необов'язкова** опція конфігурації.

---

### Модель

Використовуйте конфігурацію `model`, щоб перевизначити модель за замовчуванням для цієї команди.

```json title="aigcfroge.json"
{
  "command": {
    "analyze": {
      "model": "anthropic/claude-3-5-sonnet-20241022"
    }
  }
}
```

Це **необов'язкова** опція конфігурації.

---

## Вбудовані

aigcfroge включає кілька вбудованих команд, як-от `/init`, `/undo`, `/redo`, `/share`, `/help`; [дізнатися більше](/docs/tui#commands).

:::note
Спеціальні команди можуть перевизначати вбудовані команди.
:::

Якщо ви визначите спеціальну команду з такою самою назвою, вона перевизначить вбудовану команду.
