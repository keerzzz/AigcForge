---
title: Інструменти
description: Керуйте інструментами, які може використовувати LLM.
---

Інструменти дозволяють LLM виконувати дії у вашій кодовій базі. Aigcfroge постачається з набором вбудованих інструментів, але ви можете розширити його за допомогою [власних інструментів](/docs/custom-tools) або [серверів MCP](/docs/mcp-servers).

За замовчуванням усі інструменти **увімкнені** й не потребують дозволу для запуску. Ви можете керувати поведінкою інструментів через [дозволи](/docs/permissions).

---

## Конфігурація

Використовуйте поле `permission`, щоб керувати поведінкою інструментів. Ви можете дозволити, заборонити або вимагати схвалення для кожного інструмента.

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "permission": {
    "edit": "deny",
    "bash": "ask",
    "webfetch": "allow"
  }
}
```

Ви також можете використовувати підстановочні символи, щоб керувати кількома інструментами одночасно. Наприклад, щоб вимагати схвалення для всіх інструментів із сервера MCP:

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "permission": {
    "mymcp_*": "ask"
  }
}
```

[Дізнатися більше](/docs/permissions) про налаштування дозволів.

---

## Вбудовані

Ось усі вбудовані інструменти, доступні в Aigcfroge.

---

### bash

Виконуйте команди оболонки в середовищі вашого проєкту.

```json title="aigcfroge.json" {4}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "permission": {
    "bash": "allow"
  }
}
```

Цей інструмент дозволяє LLM виконувати команди термінала, як-от `npm install`, `git status`, або будь-яку іншу команду оболонки.

---

### edit

Змінюйте наявні файли за допомогою точних замін рядків.

```json title="aigcfroge.json" {4}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "permission": {
    "edit": "allow"
  }
}
```

Цей інструмент виконує точні зміни у файлах, замінюючи точні збіги тексту. Це основний спосіб, яким LLM змінює код.

---

### write

Створюйте нові файли або перезаписуйте наявні.

```json title="aigcfroge.json" {4}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "permission": {
    "edit": "allow"
  }
}
```

Використовуйте це, щоб дозволити LLM створювати нові файли. Він перезапише наявні файли, якщо вони вже існують.

:::note
Інструмент `write` контролюється дозволом `edit`, який охоплює всі зміни файлів (`edit`, `write`, `apply_patch`).
:::

---

### read

Читайте вміст файлів з вашої кодової бази.

```json title="aigcfroge.json" {4}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "permission": {
    "read": "allow"
  }
}
```

Цей інструмент читає файли та повертає їхній вміст. Він підтримує читання певних діапазонів рядків для великих файлів.

---

### grep

Шукайте у вмісті файлів за допомогою регулярних виразів.

```json title="aigcfroge.json" {4}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "permission": {
    "grep": "allow"
  }
}
```

Швидкий пошук у вмісті по всій кодовій базі. Підтримує повний синтаксис регулярних виразів і фільтрацію за шаблонами файлів.

---

### glob

Знаходьте файли за зіставленням із шаблоном.

```json title="aigcfroge.json" {4}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "permission": {
    "glob": "allow"
  }
}
```

Шукайте файли за допомогою glob-шаблонів, як-от `**/*.js` або `src/**/*.ts`. Повертає шляхи відповідних файлів, відсортовані за часом зміни.

---

### lsp (експериментальний)

Взаємодійте з вашими налаштованими серверами LSP, щоб отримувати функції інтелектуального аналізу коду, як-от визначення, посилання, інформацію під час наведення та ієрархію викликів.

:::note
Цей інструмент доступний лише тоді, коли `AIGCFROGE_EXPERIMENTAL_LSP_TOOL=true` (або `AIGCFROGE_EXPERIMENTAL=true`).
:::

```json title="aigcfroge.json" {4}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "permission": {
    "lsp": "allow"
  }
}
```

Підтримувані операції включають `goToDefinition`, `findReferences`, `hover`, `documentSymbol`, `workspaceSymbol`, `goToImplementation`, `prepareCallHierarchy`, `incomingCalls` та `outgoingCalls`.

Щоб налаштувати, які сервери LSP доступні для вашого проєкту, див. [Сервери LSP](/docs/lsp).

---

### apply_patch

Застосовуйте патчі до файлів.

```json title="aigcfroge.json" {4}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "permission": {
    "edit": "allow"
  }
}
```

Цей інструмент застосовує файли патчів до вашої кодової бази. Корисний для застосування дифів і патчів із різних джерел.

Під час обробки хуків `tool.execute.before` або `tool.execute.after` перевіряйте `input.tool === "apply_patch"` (не `"patch"`).

`apply_patch` використовує `output.args.patchText` замість `output.args.filePath`. Шляхи вбудовані в маркерні рядки всередині `patchText` і є відносними до кореня проєкту (наприклад: `*** Add File: src/new-file.ts`, `*** Update File: src/existing.ts`, `*** Move to: src/renamed.ts`, `*** Delete File: src/obsolete.ts`).

:::note
Інструмент `apply_patch` контролюється дозволом `edit`, який охоплює всі зміни файлів (`edit`, `write`, `apply_patch`).
:::

---

### skill

Завантажте [навичку](/docs/skills) (файл `SKILL.md`) і поверніть її вміст у розмову.

```json title="aigcfroge.json" {4}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "permission": {
    "skill": "allow"
  }
}
```

---

### todowrite

Керуйте списками завдань під час сесій програмування.

```json title="aigcfroge.json" {4}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "permission": {
    "todowrite": "allow"
  }
}
```

Створює та оновлює списки завдань, щоб відстежувати прогрес під час складних операцій. LLM використовує це для організації багатокрокових завдань.

:::note
Цей інструмент вимкнено для підагентів за замовчуванням, але ви можете ввімкнути його вручну. [Дізнатися більше](/docs/agents/#permissions)
:::

---

### webfetch

Отримуйте веб-контент.

```json title="aigcfroge.json" {4}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "permission": {
    "webfetch": "allow"
  }
}
```

Дозволяє LLM отримувати та читати веб-сторінки. Корисно для пошуку документації або дослідження онлайн-ресурсів.

---

### websearch

Шукайте інформацію в інтернеті.

:::note
Цей інструмент доступний лише тоді, коли використовується провайдер Aigcfroge або коли змінна середовища `AIGCFROGE_ENABLE_EXA` має будь-яке значення truthy (наприклад, `true` або `1`).

Щоб увімкнути його під час запуску Aigcfroge:

```bash
AIGCFROGE_ENABLE_EXA=1 aigcfroge
```

:::

```json title="aigcfroge.json" {4}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "permission": {
    "websearch": "allow"
  }
}
```

Виконує веб-пошук за допомогою Exa AI, щоб знаходити релевантну інформацію онлайн. Корисно для дослідження тем, пошуку поточних подій або збору інформації поза межами відрізу даних навчання.

API-ключ не потрібен — інструмент підключається безпосередньо до хостингованого MCP-сервісу Exa AI без автентифікації.

:::tip
Використовуйте `websearch`, коли вам потрібно знайти інформацію (пошук), і `webfetch`, коли потрібно отримати вміст із конкретного URL (отримання).
:::

---

### question

Ставте користувачеві запитання під час виконання.

```json title="aigcfroge.json" {4}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "permission": {
    "question": "allow"
  }
}
```

Цей інструмент дозволяє LLM ставити запитання користувачеві під час виконання завдання. Він корисний для:

- Збору вподобань або вимог користувача
- Уточнення неоднозначних інструкцій
- Отримання рішень щодо варіантів реалізації
- Пропонування варіантів напрямку роботи

Кожне запитання містить заголовок, текст запитання та список варіантів. Користувачі можуть вибрати один із наданих варіантів або ввести власну відповідь. Коли запитань кілька, користувачі можуть переходити між ними перед надсиланням усіх відповідей.

---

## Власні інструменти

Власні інструменти дозволяють визначати власні функції, які може викликати LLM. Вони визначаються у вашому файлі конфігурації та можуть виконувати довільний код.

[Дізнатися більше](/docs/custom-tools) про створення власних інструментів.

---

## Сервери MCP

Сервери MCP (Model Context Protocol) дозволяють інтегрувати зовнішні інструменти та сервіси. Це включає доступ до баз даних, інтеграції з API та сторонні сервіси.

[Дізнатися більше](/docs/mcp-servers) про налаштування серверів MCP.

---

## Внутрішні деталі

Внутрішньо такі інструменти, як `grep` і `glob`, використовують [ripgrep](https://github.com/BurntSushi/ripgrep) під капотом. За замовчуванням ripgrep враховує шаблони `.gitignore`, тобто файли та каталоги, зазначені у вашому `.gitignore`, будуть виключені з пошуку та переліків.

---

### Шаблони ігнорування

Щоб включити файли, які зазвичай ігноруються, створіть файл `.ignore` у корені вашого проєкту. Цей файл може явно дозволяти певні шляхи.

```text title=".ignore"
!node_modules/
!dist/
!build/
```

Наприклад, цей файл `.ignore` дозволяє ripgrep шукати всередині каталогів `node_modules/`, `dist/` та `build/`, навіть якщо вони зазначені в `.gitignore`.
