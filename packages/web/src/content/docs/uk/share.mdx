---
title: Обмін
description: Діліться вашими розмовами в Aigcfroge.
---

Функція обміну Aigcfroge дозволяє створювати публічні посилання на ваші розмови в Aigcfroge, щоб ви могли співпрацювати з колегами або отримувати допомогу від інших.

:::note
Спільні розмови загальнодоступні для будь-кого, хто має посилання.
:::

---

## Як це працює

Коли ви ділитеся розмовою, Aigcfroge:

1. Створює унікальну публічну URL-адресу для вашої сесії
2. Синхронізує історію вашої розмови з нашими серверами
3. Робить розмову доступною через посилання для обміну — `opncd.ai/s/<share-id>`

---

## Обмін

Aigcfroge підтримує три режими обміну, які контролюють, як поширюються розмови:

---

### Вручну (за замовчуванням)

За замовчуванням Aigcfroge використовує ручний режим обміну. Сесії не поширюються автоматично, але ви можете поділитися ними вручну за допомогою команди `/share`:

```
/share
```

Це згенерує унікальну URL-адресу, яку буде скопійовано в буфер обміну.

Щоб явно встановити ручний режим у вашому [файлі конфігурації](/docs/config):

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "share": "manual"
}
```

---

### Автоматичний обмін

Ви можете ввімкнути автоматичний обмін для всіх нових розмов, встановивши параметр `share` на значення `"auto"` у вашому [файлі конфігурації](/docs/config):

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "share": "auto"
}
```

З увімкненим автоматичним обміном кожна нова розмова автоматично поширюватиметься, і буде згенеровано посилання.

---

### Вимкнено

Ви можете повністю вимкнути обмін, встановивши параметр `share` на значення `"disabled"` у вашому [файлі конфігурації](/docs/config):

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "share": "disabled"
}
```

Щоб застосувати це для всієї вашої команди в конкретному проєкті, додайте його до `aigcfroge.json` у вашому проєкті та закомітьте в Git.

---

## Скасування обміну

Щоб припинити поширення розмови та прибрати її з публічного доступу:

```
/unshare
```

Це видалить посилання для обміну та знищить дані, пов'язані з розмовою.

---

## Конфіденційність

Є кілька речей, про які слід пам'ятати під час обміну розмовою.

---

### Зберігання даних

Спільні розмови залишаються доступними, доки ви явно не скасуєте обмін ними. Це включає:

- Повну історію розмови
- Усі повідомлення та відповіді
- Метадані сесії

---

### Рекомендації

- Діліться лише розмовами, які не містять чутливої інформації.
- Переглядайте вміст розмови перед поширенням.
- Скасовуйте обмін розмовами після завершення співпраці.
- Уникайте обміну розмовами з пропрієтарним кодом або конфіденційними даними.
- Для чутливих проєктів повністю вимикайте обмін.

---

## Для підприємств

Для корпоративних розгортань функцію обміну можна:

- **Вимкнути** повністю для відповідності вимогам безпеки
- **Обмежити** лише користувачами, автентифікованими через SSO
- **Розмістити на власній інфраструктурі**

[Дізнайтеся більше](/docs/enterprise) про використання aigcfroge у вашій організації.
