CLI Aigcfroge за замовчуванням запускає [TUI](/docs/tui), коли запускається без жодних аргументів.

```bash
aigcfroge
```

Але він також приймає команди, як задокументовано на цій сторінці. Це дозволяє взаємодіяти з Aigcfroge програмно.

```bash
aigcfroge run "Explain how closures work in JavaScript"
```

---

### tui

Запустіть термінальний інтерфейс користувача Aigcfroge.

```bash
aigcfroge [project]
```

#### Прапорці

| Flag                                        | Short | Опис                                                                 |
| ------------------------------------------- | ----- | -------------------------------------------------------------------- |
| <nobr><code>{"--continue"}</code></nobr>    | `-c`  | Продовжити останню сесію                                              |
| <nobr><code>{"--session"}</code></nobr>     | `-s`  | ID сесії для продовження                                              |
| <nobr><code>{"--fork"}</code></nobr>        |       | Розгалужити сесію під час продовження (використовуйте з `--continue` або `--session`) |
| <nobr><code>{"--prompt"}</code></nobr>      |       | Промпт для використання                                               |
| <nobr><code>{"--model"}</code></nobr>       | `-m`  | Модель у форматі провайдер/модель                                     |
| <nobr><code>{"--agent"}</code></nobr>       |       | Агент для використання                                                |
| <nobr><code>{"--port"}</code></nobr>        |       | Порт для прослуховування                                              |
| <nobr><code>{"--hostname"}</code></nobr>    |       | Ім'я хоста для прослуховування                                        |
| <nobr><code>{"--mdns"}</code></nobr>        |       | Увімкнути виявлення mDNS                                              |
| <nobr><code>{"--mdns-domain"}</code></nobr> |       | Власне доменне ім'я mDNS                                              |
| <nobr><code>{"--cors"}</code></nobr>        |       | Додаткові джерела (origin) браузера, для яких дозволено CORS          |

## Команди

CLI Aigcfroge також має такі команди.

---

### agent

Керування агентами Aigcfroge.

```bash
aigcfroge agent [command]
```

---

#### create

Створіть нового агента з власною конфігурацією.

```bash
aigcfroge agent create
```

Ця команда проведе вас через створення нового агента з власним системним промптом і конфігурацією дозволів. Усе, чого ви не дозволите, буде заборонено у frontmatter згенерованого агента.

#### Прапорці

| Flag                                        | Short | Опис                                                                                                                                                                                                                         |
| ------------------------------------------- | ----- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <nobr><code>{"--path"}</code></nobr>        |       | Каталог для запису файлу агента (за замовчуванням глобальний або `.aigcfroge/agent`, залежно від промпта)                                                                                                                   |
| <nobr><code>{"--description"}</code></nobr> |       | Що агент має робити                                                                                                                                                                                                           |
| <nobr><code>{"--mode"}</code></nobr>        |       | Режим агента: `all`, `primary` або `subagent`                                                                                                                                                                                 |
| <nobr><code>{"--permissions"}</code></nobr> |       | Список дозволів через кому (за замовчуванням: усі). Доступні: `bash`, `read`, `edit`, `glob`, `grep`, `webfetch`, `task`, `todowrite`, `websearch`, `lsp`, `skill`. Усе, що пропущено, заборонено. Псевдонім: `--tools`    |
| <nobr><code>{"--model"}</code></nobr>       | `-m`  | Модель у форматі `провайдер/модель`                                                                                                                                                                                            |

Передача всіх `--path`, `--description`, `--mode` та `--permissions` запускає команду без інтерактивного режиму.

### attach

Підключіть термінал до вже запущеного сервера Aigcfroge, який стартував через команди `serve` або `web`.

```bash
aigcfroge attach [url]
```

Це дозволяє використовувати TUI з віддаленим сервером Aigcfroge. Наприклад:

```bash
# Start the backend server for web/mobile access
aigcfroge web --port 4096 --hostname 0.0.0.0

# In another terminal, attach the TUI to the running backend
aigcfroge attach http://10.20.30.40:4096
```

#### Прапорці

| Flag                                     | Short | Опис                                                                   |
| ---------------------------------------- | ----- | ---------------------------------------------------------------------- |
| <nobr><code>{"--dir"}</code></nobr>      |       | Робочий каталог для запуску TUI                                        |
| <nobr><code>{"--continue"}</code></nobr> | `-c`  | Продовжити останню сесію                                               |
| <nobr><code>{"--session"}</code></nobr>  | `-s`  | ID сесії для продовження                                               |
| <nobr><code>{"--fork"}</code></nobr>     |       | Розгалужити сесію під час продовження (використовуйте з `--continue` або `--session`) |
| <nobr><code>{"--password"}</code></nobr> | `-p`  | Пароль базової автентифікації (за замовчуванням `AIGCFROGE_SERVER_PASSWORD`)            |
| <nobr><code>{"--username"}</code></nobr> | `-u`  | Ім'я користувача базової автентифікації (за замовчуванням `AIGCFROGE_SERVER_USERNAME` або `aigcfroge`) |

### auth

Команда для керування обліковими даними та входом для провайдерів.

```bash
aigcfroge auth [command]
```

---

#### login

Aigcfroge працює на основі списку провайдерів на [Models.dev](https://models.dev), тож ви можете використати `aigcfroge auth login`, щоб налаштувати API-ключі для будь-якого провайдера, який хочете використовувати. Це зберігається у `~/.local/share/aigcfroge/auth.json`.

```bash
aigcfroge auth login
```

Під час запуску Aigcfroge завантажує провайдерів з файлу облікових даних, а також будь-які ключі, визначені у вашому середовищі або у файлі `.env` у вашому проєкті.

##### Прапорці

| Flag                                     | Short | Опис                                                  |
| ---------------------------------------- | ----- | ----------------------------------------------------- |
| <nobr><code>{"--provider"}</code></nobr> | `-p`  | ID або назва провайдера для входу                     |
| <nobr><code>{"--method"}</code></nobr>   | `-m`  | Назва методу входу, пропускаючи вибір методу          |

---

#### list

Виводить перелік усіх автентифікованих провайдерів, що зберігаються у файлі облікових даних.

```bash
aigcfroge auth list
```

Або скорочений варіант.

```bash
aigcfroge auth ls
```

---

#### logout

Виходить з провайдера, видаляючи його з файлу облікових даних.

```bash
aigcfroge auth logout
```

#### add


Ця команда проведе вас через додавання локального або віддаленого MCP-сервера.

---

#### list

Виводить перелік усіх налаштованих MCP-серверів та їхній статус підключення.

```bash
aigcfroge mcp list
```

Або скористайтеся скороченим варіантом.

```bash
aigcfroge mcp ls
```

---

#### auth

Автентифікуйтеся з MCP-сервером, що підтримує OAuth.

```bash
aigcfroge mcp auth [name]
```

Якщо ви не вкажете назву сервера, вам буде запропоновано вибрати з доступних серверів, що підтримують OAuth.

Ви також можете перелічити сервери, що підтримують OAuth, та їхній статус автентифікації.

```bash
aigcfroge mcp auth list
```

Або скористайтеся скороченим варіантом.

```bash
aigcfroge mcp auth ls
```

---

#### logout

Видаляє облікові дані OAuth для MCP-сервера.

```bash
aigcfroge mcp logout [name]
```

---

#### debug

Налагодження проблем підключення OAuth для MCP-сервера.

```bash
aigcfroge mcp debug <name>
```

### models

Виводить перелік усіх доступних моделей з налаштованих провайдерів.

```bash
aigcfroge models [provider]
```

Ця команда показує всі моделі, доступні у ваших налаштованих провайдерів, у форматі `провайдер/модель`.

Це корисно, щоб визначити точну назву моделі для використання у [вашій конфігурації](/docs/config/).

Ви можете за бажанням передати ID провайдера, щоб відфільтрувати моделі за цим провайдером.

```bash
aigcfroge models anthropic
```

#### Прапорці

| Flag                                    | Опис                                                            |
| --------------------------------------- | --------------------------------------------------------------- |
| <nobr><code>{"--refresh"}</code></nobr> | Оновити кеш моделей з models.dev                                |
| <nobr><code>{"--verbose"}</code></nobr> | Використовувати детальніший вивід моделей (включає метадані, як-от вартість) |

Використовуйте прапорець `--refresh`, щоб оновити кешований список моделей. Це корисно, коли до провайдера додано нові моделі і ви хочете побачити їх у Aigcfroge.

```bash
aigcfroge models --refresh
```

### run

Запускає aigcfroge у неінтерактивному режимі, передаючи промпт безпосередньо.

```bash
aigcfroge run [message..]
```

Це корисно для скриптів, автоматизації або коли ви хочете швидку відповідь без запуску повного TUI. Наприклад:

```bash "aigcfroge run"
aigcfroge run Explain the use of context in Go
```

Ви також можете підключитися до запущеного екземпляра `aigcfroge serve`, щоб уникнути холодного старту MCP-серверів під час кожного запуску:

```bash
# Start a headless server in one terminal
aigcfroge serve

# In another terminal, run commands that attach to it
aigcfroge run --attach http://localhost:4096 "Explain async/await in JavaScript"
```

| <nobr><code>{"--model"}</code></nobr>                        | `-m`  | Модель у форматі провайдер/модель                                    |

### serve

Запускає безголовий сервер Aigcfroge для доступу через API. Перегляньте [документацію сервера](/docs/server), щоб дізнатися про повний HTTP-інтерфейс.

```bash
aigcfroge serve
```

Це запускає HTTP-сервер, який надає API-доступ до функціональності aigcfroge без інтерфейсу TUI. Встановіть `AIGCFROGE_SERVER_PASSWORD`, щоб увімкнути базову HTTP-автентифікацію (ім'я користувача за замовчуванням — `aigcfroge`).

#### Прапорці

| <nobr><code>{"--port"}</code></nobr>        | Порт для прослуховування                                    |
| <nobr><code>{"--hostname"}</code></nobr>    | Ім'я хоста для прослуховування                              |
| <nobr><code>{"--mdns"}</code></nobr>        | Увімкнути виявлення mDNS                                    |
| <nobr><code>{"--mdns-domain"}</code></nobr> | Власне доменне ім'я mDNS                                    |
| <nobr><code>{"--cors"}</code></nobr>        | Додаткові джерела (origin) браузера, для яких дозволено CORS |

| <nobr><code>{"--format"}</code></nobr> | Формат виводу: `json` або `tsv` |

Виводить шлях до бази даних.

```bash
aigcfroge db path
```

### debug

Інструменти налагодження та усунення неполадок.

```bash
aigcfroge debug [command]
```

### uninstall

Видаляє Aigcfroge та всі пов'язані файли.

```bash
aigcfroge uninstall
```

#### Прапорці

| Flag                                        | Short | Опис                                                |
| ------------------------------------------- | ----- | --------------------------------------------------- |
| <nobr><code>{"--keep-config"}</code></nobr> | `-c`  | Зберегти файли конфігурації                         |
| <nobr><code>{"--keep-data"}</code></nobr>   | `-d`  | Зберегти дані сесій та знімки                       |
| <nobr><code>{"--dry-run"}</code></nobr>     |       | Показує, що було б видалено, без фактичного видалення |
| <nobr><code>{"--force"}</code></nobr>       | `-f`  | Пропустити запити підтвердження                     |

### upgrade

Оновлює aigcfroge до останньої версії або до конкретної версії.

```bash
aigcfroge upgrade [target]
```

Щоб оновитися до останньої версії:

```bash
aigcfroge upgrade
```

Щоб оновитися до конкретної версії:

```bash
aigcfroge upgrade v0.1.48
```

#### Прапорці

| Flag                                   | Short | Опис                                                       |
| -------------------------------------- | ----- | ---------------------------------------------------------- |
| <nobr><code>{"--method"}</code></nobr> | `-m`  | Метод встановлення, який використовувався; curl, npm, pnpm, bun, brew |
