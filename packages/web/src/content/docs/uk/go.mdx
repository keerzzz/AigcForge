Aigcfroge Go — це недорога підписка: **$5 за перший місяць**, далі **$10/місяць** — яка надає надійний доступ до популярних відкритих моделей програмування.

2. Потім ми попрацювали з кількома провайдерами, щоб переконатися, що ці моделі обслуговуються правильно.
3. Нарешті, ми протестували комбінації моделі/провайдера і склали список, який ми можемо з упевненістю рекомендувати.

## Як це працює

Aigcfroge Go працює як будь-який інший провайдер у Aigcfroge.

1. Увійдіть у **<a href={console}>Aigcfroge Zen</a>**, підпишіться на Go та скопіюйте свій ключ API.
2. Виконайте команду `/connect` у TUI, виберіть `Aigcfroge Go` та вставте свій ключ API.
3. Виконайте `/models` у TUI, щоб побачити список моделей, доступних через Go.

:::note
Лише один учасник робочого простору може підписатися на Aigcfroge Go.
