Власні інструменти — це функції, які ви створюєте і які LLM може викликати під час розмов. Вони працюють поряд із [вбудованими інструментами](/docs/tools) aigcfroge, такими як `read`, `write` та `bash`.

---

## Створення інструмента

Інструменти визначаються як файли **TypeScript** або **JavaScript**. Однак визначення інструмента може викликати скрипти, написані **будь-якою мовою** — TypeScript або JavaScript використовуються лише для самого визначення інструмента.

---

### Розташування

Їх можна розмістити:

- Локально, розмістивши їх у каталозі `.aigcfroge/tools/` вашого проєкту.
- Або глобально, розмістивши їх у `~/.config/aigcfroge/tools/`.

---

### Структура

Найпростіший спосіб створити інструменти — використати допоміжну функцію `tool()`, яка забезпечує безпеку типів і валідацію.

```ts title=".aigcfroge/tools/database.ts" {1}
import { tool } from "@aigcfroge/plugin"

export default tool({
  description: "Query the project database",
  args: {
    query: tool.schema.string().describe("SQL query to execute"),
  },
  async execute(args) {
    // Your database logic here
    return `Executed query: ${args.query}`
  },
})
```

**Назва файлу** стає **назвою інструмента**. Наведений вище приклад створює інструмент `database`.

---

#### Кілька інструментів у файлі

Ви також можете експортувати кілька інструментів з одного файлу. Кожен експорт стає **окремим інструментом** із назвою **`<filename>_<exportname>`**:

```ts title=".aigcfroge/tools/math.ts"
import { tool } from "@aigcfroge/plugin"

export const add = tool({
  description: "Add two numbers",
  args: {
    a: tool.schema.number().describe("First number"),
    b: tool.schema.number().describe("Second number"),
  },
  async execute(args) {
    return (args.a + args.b).toString()
  },
})

export const multiply = tool({
  description: "Multiply two numbers",
  args: {
    a: tool.schema.number().describe("First number"),
    b: tool.schema.number().describe("Second number"),
  },
  async execute(args) {
    return (args.a * args.b).toString()
  },
})
```

Це створює два інструменти: `math_add` і `math_multiply`.

---

#### Конфлікти назв із вбудованими інструментами

Власні інструменти ключуються за назвою інструмента. Якщо власний інструмент має таку саму назву, як вбудований, пріоритет має власний інструмент.

Наприклад, цей файл замінює вбудований інструмент `bash`:

```ts title=".aigcfroge/tools/bash.ts"
import { tool } from "@aigcfroge/plugin"

export default tool({
  description: "Restricted bash wrapper",
  args: {
    command: tool.schema.string(),
  },
  async execute(args) {
    return `blocked: ${args.command}`
  },
})
```

:::note
Віддавайте перевагу унікальним назвам, якщо ви навмисно не хочете замінити вбудований інструмент. Якщо ви хочете вимкнути вбудований інструмент, але не перевизначати його, використовуйте [дозволи](/docs/permissions).
:::

### Аргументи

Ви можете використовувати `tool.schema`, який є просто [Zod](https://zod.dev), для визначення типів аргументів.

```ts "tool.schema"
args: {
  query: tool.schema.string().describe("SQL query to execute")
}
```

Ви також можете імпортувати [Zod](https://zod.dev) безпосередньо та повертати звичайний об'єкт:

```ts {6}
import { z } from "zod"

export default {
  description: "Tool description",
  args: {
    param: z.string().describe("Parameter description"),
  },
  async execute(args, context) {
    // Tool implementation
    return "result"
  },
}
```

### Контекст

Інструменти отримують контекст поточної сесії:

```ts title=".aigcfroge/tools/project.ts" {8}
import { tool } from "@aigcfroge/plugin"

export default tool({
  description: "Get project information",
  args: {},
  async execute(args, context) {
    // Access context information
    const { agent, sessionID, messageID, directory, worktree } = context
    return `Agent: ${agent}, Session: ${sessionID}, Message: ${messageID}, Directory: ${directory}, Worktree: ${worktree}`
  },
})
```

Використовуйте `context.directory` для робочого каталогу сесії.
Використовуйте `context.worktree` для кореня робочого дерева git.

## Приклади

### Написання інструмента на Python

Ви можете писати інструменти будь-якою мовою. Ось приклад, який додає два числа за допомогою Python.

Спочатку створіть інструмент як скрипт Python:

```python title=".aigcfroge/tools/add.py"
import sys

a = int(sys.argv[1])
b = int(sys.argv[2])
print(a + b)
```

Потім створіть визначення інструмента, яке його викликає:

```ts title=".aigcfroge/tools/python-add.ts" {10}
import { tool } from "@aigcfroge/plugin"
import path from "path"

export default tool({
  description: "Add two numbers using Python",
  args: {
    a: tool.schema.number().describe("First number"),
    b: tool.schema.number().describe("Second number"),
  },
  async execute(args, context) {
    const script = path.join(context.worktree, ".aigcfroge/tools/add.py")
    const result = await Bun.$`python3 ${script} ${args.a} ${args.b}`.text()
    return result.trim()
  },
})
```

Тут ми використовуємо утиліту [`Bun.$`](https://bun.com/docs/runtime/shell), щоб запустити скрипт Python.
