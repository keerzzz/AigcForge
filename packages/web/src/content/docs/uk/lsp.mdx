Aigcfroge може інтегруватися з серверами Language Server Protocol (LSP), щоб використовувати діагностику як зворотний зв'язок для агента.

---

LSP вимкнено за замовчуванням. Після ввімкнення сервери запускаються, коли виявлено одне з наведених вище розширень файлів і виконано вимоги.

:::note
Ви можете вимкнути автоматичне завантаження LSP-серверів, встановивши змінну середовища `AIGCFROGE_DISABLE_LSP_DOWNLOAD` у значення `true`.
:::

## Як це працює

Коли LSP увімкнено та aigcfroge відкриває файл, він:

1. Перевіряє розширення файлу на відповідність усім увімкненим LSP-серверам.
2. Запускає відповідний LSP-сервер, якщо він ще не запущений.

---

## Найкращі практики

LSP може допомогти агенту знаходити та виправляти проблеми, надаючи діагностику від мовних серверів. Це корисно в деяких проєктах, але не завжди є безперечною перевагою.

Мовні сервери можуть розсинхронізовуватися, використовувати значний обсяг пам'яті, відрізнятися залежно від версії чи проєкту та сповільнювати робочі процеси агента. У багатьох проєктах краще, щоб агент запускав lint, typecheck або інші діагностичні CLI-інструменти безпосередньо, щоб помилки поверталися в цикл агента без цих компромісів. Документуйте ці команди у файлах інструкцій, таких як `AGENTS.md`, або у навичках, щоб агент знав, що запускати. Вмикайте LSP, коли ваш проєкт отримує користь від додаткового зворотного зв'язку від мовних серверів.

## Налаштування

Ви можете вмикати та налаштовувати LSP-сервери через розділ `lsp` у вашій конфігурації aigcfroge.

Щоб увімкнути всі вбудовані LSP-сервери, встановіть `lsp` у значення `true`.

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "lsp": true
}
```

Використовуйте об'єкт, щоб залишити вбудовані сервери увімкненими, водночас налаштовуючи перевизначення або власні сервери.

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "lsp": {}
}
```

Кожен налаштований запис LSP-сервера підтримує наступне:

Записи серверів потребують `command`, якщо вони лише не вимикають сервер.

| Властивість    | Тип      | Опис                                                              |
| -------------- | -------- | ----------------------------------------------------------------- |
| `disabled`     | boolean  | Встановіть `true`, щоб вимкнути LSP-сервер                        |
| `command`      | string[] | Команда для запуску LSP-сервера                                   |
| `extensions`   | string[] | Розширення файлів, з якими має працювати цей LSP-сервер           |
| `env`          | object   | Змінні середовища для встановлення під час запуску сервера        |
| `initialization` | object | Параметри ініціалізації для надсилання LSP-серверу                |

Розгляньмо кілька прикладів.

---

### Змінні середовища

Використовуйте властивість `env`, щоб встановити змінні середовища під час запуску LSP-сервера:

```json title="aigcfroge.json" {5-8}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "lsp": {
    "rust": {
      "command": ["rust-analyzer"],
      "env": {
        "RUST_LOG": "debug"
      }
    }
  }
}
```

---

### Параметри ініціалізації

Використовуйте властивість `initialization`, щоб передати параметри ініціалізації LSP-серверу. Це специфічні для сервера налаштування, які надсилаються під час запиту `initialize` LSP:

```json title="aigcfroge.json" {5-13}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "lsp": {
    "custom-lsp": {
      "command": ["custom-lsp-server", "--stdio"],
      "extensions": [".custom"],
      "initialization": {
        "preferences": {
          "importModuleSpecifierPreference": "relative"
        }
      }
    }
  }
}
```

:::note
Параметри ініціалізації відрізняються залежно від LSP-сервера. Ознайомтеся з документацією вашого LSP-сервера, щоб дізнатися про доступні параметри.
:::

---

### Вимкнення LSP-серверів

Якщо `lsp` не вказано, усі LSP-сервери вимкнено. Щоб вимкнути всі LSP-сервери після того, як інша конфігурація їх увімкнула, встановіть `lsp` у значення `false`:

```json title="aigcfroge.json" {3}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "lsp": false
}
```

Щоб вимкнути **конкретний** LSP-сервер, встановіть `disabled` у значення `true`:

```json title="aigcfroge.json" {5}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "lsp": {
    "typescript": {
      "disabled": true
    }
  }
}
```

---

### Власні LSP-сервери

Ви можете додавати власні LSP-сервери, вказавши команду та розширення файлів:

```json title="aigcfroge.json" {4-7}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "lsp": {
    "custom-lsp": {
      "command": ["custom-lsp-server", "--stdio"],
      "extensions": [".custom"]
    }
  }
}
```

## Додаткова інформація

### PHP Intelephense

PHP Intelephense пропонує преміум-функції через ліцензійний ключ. Ви можете надати ліцензійний ключ, розмістивши (лише) ключ у текстовому файлі за адресою:

- На macOS/Linux: `$HOME/intelephense/license.txt`
- На Windows: `%USERPROFILE%/intelephense/license.txt`

Файл має містити лише ліцензійний ключ без додаткового вмісту.
