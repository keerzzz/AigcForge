Aigcfroge може працювати як вебзастосунок у вашому браузері, надаючи той самий потужний досвід AI-програмування без потреби в терміналі.

![Aigcfroge Web — Нова сесія](../../../assets/web/web-homepage-new-session.png)

## Початок роботи

Запустіть вебінтерфейс командою:

```bash
aigcfroge web
```

Це запускає локальний сервер на `127.0.0.1` із випадковим доступним портом і автоматично відкриває Aigcfroge у вашому браузері за замовчуванням.

:::caution
Якщо `AIGCFROGE_SERVER_PASSWORD` не встановлено, сервер не буде захищеним. Для локального використання це нормально, але для доступу через мережу його слід встановити.
:::

:::tip[Користувачі Windows]
Для найкращого досвіду запускайте `aigcfroge web` із [WSL](/docs/windows-wsl), а не з PowerShell. Це забезпечує належний доступ до файлової системи та інтеграцію з терміналом.
:::

## Конфігурація

Ви можете налаштувати вебсервер за допомогою прапорців командного рядка або у [конфігураційному файлі](/docs/config).

### Порт

За замовчуванням Aigcfroge обирає доступний порт. Ви можете вказати порт:

```bash
aigcfroge web --port 4096
```

### Ім'я хоста

За замовчуванням сервер прив'язується до `127.0.0.1` (лише localhost). Щоб зробити Aigcfroge доступним у вашій мережі:

```bash
aigcfroge web --hostname 0.0.0.0
```

Під час використання `0.0.0.0` Aigcfroge покаже і локальну, і мережеву адреси:

```
  Local access:       http://localhost:4096
  Network access:     http://192.168.1.100:4096
```

### Виявлення mDNS

Увімкніть mDNS, щоб ваш сервер можна було виявити в локальній мережі:

```bash
aigcfroge web --mdns
```

Це автоматично встановлює ім'я хоста на `0.0.0.0` і оголошує сервер як `aigcfroge.local`.

Ви можете налаштувати ім'я домену mDNS, щоб запускати кілька екземплярів в одній мережі:

```bash
aigcfroge web --mdns --mdns-domain myproject.local
```

### CORS

Щоб дозволити додаткові домени для CORS (корисно для власних фронтендів):

```bash
aigcfroge web --cors https://example.com
```

### Автентифікація

Щоб захистити доступ, встановіть пароль за допомогою змінної середовища `AIGCFROGE_SERVER_PASSWORD`:

```bash
AIGCFROGE_SERVER_PASSWORD=secret aigcfroge web
```

Ім'я користувача за замовчуванням — `aigcfroge`, але його можна змінити за допомогою `AIGCFROGE_SERVER_USERNAME`.

## Використання вебінтерфейсу

Після запуску вебінтерфейс надає доступ до ваших сесій Aigcfroge.

### Сесії

Переглядайте та керуйте своїми сесіями з головної сторінки. Ви можете бачити активні сесії та починати нові.

![Aigcfroge Web — Активна сесія](../../../assets/web/web-homepage-active-session.png)

### Статус сервера

Натисніть «Переглянути сервери», щоб переглянути підключені сервери та їхній статус.

![Aigcfroge Web — Перегляд серверів](../../../assets/web/web-homepage-see-servers.png)

## Приєднання термінала

Ви можете приєднати термінальний TUI до запущеного вебсервера:

```bash
# Start the web server
aigcfroge web --port 4096

# In another terminal, attach the TUI
aigcfroge attach http://localhost:4096
```

Це дає змогу використовувати вебінтерфейс і термінал одночасно, розділяючи ті самі сесії та стан.

---

## Конфігураційний файл

Ви також можете налаштувати параметри сервера у вашому конфігураційному файлі `aigcfroge.json`:

```json
{
  "server": {
    "port": 4096,
    "hostname": "0.0.0.0",
    "mdns": true,
    "cors": ["https://example.com"]
  }
}
```

Прапорці командного рядка мають пріоритет над налаштуваннями конфігураційного файлу.
