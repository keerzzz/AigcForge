За допомогою Aigcfroge ви можете вибрати одну з кількох вбудованих тем, використовувати тему, яка адаптується до теми вашого термінала, або створити власну тему.

За замовчуванням Aigcfroge використовує власну тему `aigcfroge`.

---

## Вимоги до термінала

Щоб теми відображалися коректно з повною палітрою кольорів, ваш термінал має підтримувати **truecolor** (24-бітний колір). Більшість сучасних терміналів підтримують це за замовчуванням, але вам може знадобитися ввімкнути це:

- **Перевірте підтримку**: виконайте `echo $COLORTERM` — він має вивести `truecolor` або `24bit`
- **Увімкніть truecolor**: встановіть змінну середовища `COLORTERM=truecolor` у профілі вашої оболонки
- **Сумісність термінала**: переконайтеся, що ваш емулятор термінала підтримує 24-бітний колір (більшість сучасних терміналів, як-от iTerm2, Alacritty, Kitty, Windows Terminal та останні версії GNOME Terminal, підтримують)

Без підтримки truecolor теми можуть відображатися зі зниженою точністю кольорів або повертатися до найближчого наближення з 256 кольорів.

## Вбудовані теми

Aigcfroge має кілька вбудованих тем.

| Назва                 | Опис                                                                        |
| --------------------- | --------------------------------------------------------------------------- |

| `tokyonight`          | На основі теми [Tokyonight](https://github.com/folke/tokyonight.nvim)       |
| `everforest`          | На основі теми [Everforest](https://github.com/sainnhe/everforest)          |
| `ayu`                 | На основі темної теми [Ayu](https://github.com/ayu-theme)                   |
| `catppuccin`          | На основі теми [Catppuccin](https://github.com/catppuccin)                  |
| `catppuccin-macchiato`| На основі теми [Catppuccin](https://github.com/catppuccin)                  |
| `gruvbox`             | На основі теми [Gruvbox](https://github.com/morhetz/gruvbox)                |

## Системна тема

Тема `system` розроблена для автоматичної адаптації до кольорової схеми вашого термінала. На відміну від традиційних тем, які використовують фіксовані кольори, тема _system_:

- **Створює шкалу сірого**: будує власну шкалу сірого на основі кольору фону вашого термінала, забезпечуючи оптимальний контраст.
- **Використовує ANSI-кольори**: застосовує стандартні ANSI-кольори (0-15) для підсвічування синтаксису та елементів інтерфейсу, поважаючи палітру кольорів вашого термінала.
- **Зберігає типові налаштування термінала**: використовує `none` для кольорів тексту та фону, щоб зберегти природний вигляд вашого термінала.

Системна тема призначена для користувачів, які:

- Хочуть, щоб Aigcfroge відповідав вигляду їхнього термінала
- Використовують власні кольорові схеми термінала
- Віддають перевагу узгодженому вигляду в усіх термінальних застосунках

---

## Використання теми

Ви можете вибрати тему, відкривши вибір теми командою `/theme`. Або можете вказати її у файлі `tui.json`.

```json title="tui.json" {3}
{
  "$schema": "https://aigcfroge.ai/tui.json",
  "theme": "tokyonight"
}
```

## Власні теми

Aigcfroge підтримує гнучку систему тем на основі JSON, яка дозволяє користувачам легко створювати та налаштовувати теми.

---

### Ієрархія

Теми завантажуються з кількох каталогів у такому порядку, де пізніші каталоги перевизначають попередні:

1. **Вбудовані теми** — вони вбудовані у двійковий файл
2. **Каталог конфігурації користувача** — визначається у `~/.config/aigcfroge/themes/*.json` або `$XDG_CONFIG_HOME/aigcfroge/themes/*.json`
3. **Кореневий каталог проєкту** — визначається у `<project-root>/.aigcfroge/themes/*.json`
4. **Поточний робочий каталог** — визначається у `./.aigcfroge/themes/*.json`

Якщо кілька каталогів містять тему з однаковою назвою, буде використано тему з каталогу з вищим пріоритетом.

---

### Створення теми

Щоб створити власну тему, створіть файл JSON в одному з каталогів тем.

Для тем на рівні користувача:

```bash no-frame
mkdir -p ~/.config/aigcfroge/themes
vim ~/.config/aigcfroge/themes/my-theme.json
```

А для тем, специфічних для проєкту:

```bash no-frame
mkdir -p .aigcfroge/themes
vim .aigcfroge/themes/my-theme.json
```

---

### Формат JSON

Теми використовують гнучкий формат JSON із підтримкою:

- **Hex-кольори**: `"#ffffff"`
- **ANSI-кольори**: `3` (0-255)
- **Посилання на кольори**: `"primary"` або власні визначення
- **Темні/світлі варіанти**: `{"dark": "#000", "light": "#fff"}`
- **Без кольору**: `"none"` — використовує типовий колір термінала або прозорість

---

### Визначення кольорів

Розділ `defs` необов'язковий і дозволяє визначити кольори багаторазового використання, на які можна посилатися в темі.

---

### Типові значення термінала

Спеціальне значення `"none"` можна використовувати для будь-якого кольору, щоб успадкувати типовий колір термінала. Це особливо корисно для створення тем, які бездоганно поєднуються зі схемою кольорів вашого термінала:

- `"text": "none"` — використовує типовий колір переднього плану термінала
- `"background": "none"` — використовує типовий колір фону термінала
