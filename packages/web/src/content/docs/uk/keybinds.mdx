  :::

## Клавіша-лідер

Aigcfroge використовує клавішу `leader` для багатьох сполучень клавіш. Це дозволяє уникнути конфліктів у вашому терміналі.

За замовчуванням клавішею-лідером є `ctrl+x`, і багато дій вимагають спочатку натиснути клавішу-лідер, а потім сполучення. Наприклад, щоб розпочати нову сесію, спочатку натисніть `ctrl+x`, а потім `n`.

Вам не обов'язково використовувати клавішу-лідер для своїх сполучень, але ми рекомендуємо це робити.

Деякі навігаційні сполучення клавіш навмисно не використовують клавішу-лідер за замовчуванням. Для сесій субагентів типові значення: `session_child_first` = `<leader>down`, `session_child_cycle` = `right`, `session_child_cycle_reverse` = `left` та `session_parent` = `up`.

`leader_timeout` контролює, як довго Aigcfroge чекає на наступну клавішу після клавіші-лідера. За замовчуванням це `2000` мілісекунд.

## Значення сполучень

Рядок може містити одне сполучення або кілька сполучень через кому. Для кількох сполучень також можна використовувати масив.

Для складніших випадків використовуйте об'єкт із `key`, `event`, `preventDefault` або `fallthrough`.

```json title="tui.json"
{
  "$schema": "https://aigcfroge.ai/tui.json",
  "keybinds": {
    "messages_copy": ["<leader>y", "ctrl+shift+c"],
    "input_paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

---

## Вимкнення сполучення клавіш

Ви можете вимкнути сполучення клавіш, додавши клавішу у `tui.json` зі значенням `"none"` або `false`.

```json title="tui.json"
{
  "$schema": "https://aigcfroge.ai/tui.json",
  "keybinds": {
    "session_compact": "none"
  }
}
```

## Сполучення клавіш у полі введення десктопного застосунку

Поле введення запиту в десктопному застосунку Aigcfroge підтримує поширені сполучення у стилі Readline/Emacs для редагування тексту. Вони вбудовані й наразі не налаштовуються через `aigcfroge.json`.

| Сполучення | Дія                                             |
| ---------- | ------------------------------------------------ |
| `ctrl+a`   | Переміститися на початок поточного рядка         |
| `ctrl+e`   | Переміститися в кінець поточного рядка           |
| `ctrl+b`   | Перемістити курсор на один символ назад          |
| `ctrl+f`   | Перемістити курсор на один символ уперед         |
| `alt+b`    | Перемістити курсор на одне слово назад           |
| `alt+f`    | Перемістити курсор на одне слово вперед          |
| `ctrl+d`   | Видалити символ під курсором                     |
| `ctrl+k`   | Видалити до кінця рядка                          |
| `ctrl+u`   | Видалити до початку рядка                        |
| `ctrl+w`   | Видалити попереднє слово                         |
| `alt+d`    | Видалити наступне слово                          |
| `ctrl+t`   | Поміняти символи місцями                         |
| `ctrl+g`   | Скасувати спливаючі вікна / перервати поточну відповідь |

## Shift+Enter

Деякі термінали не надсилають клавіші-модифікатори разом з Enter за замовчуванням. Можливо, вам доведеться налаштувати термінал так, щоб він надсилав `Shift+Enter` як escape-послідовність.

### Windows Terminal

Відкрийте файл `settings.json` у такому розташуванні:

```
%LOCALAPPDATA%\Packages\Microsoft.WindowsTerminal_8wekyb3d8bbwe\LocalState\settings.json
```

Додайте це до масиву `actions` на кореневому рівні:

```json
"actions": [
  {
    "command": {
      "action": "sendInput",
      "input": "\u001b[13;2u"
    },
    "id": "User.sendInput.ShiftEnterCustom"
  }
]
```

Додайте це до масиву `keybindings` на кореневому рівні:

```json
"keybindings": [
  {
    "keys": "shift+enter",
    "id": "User.sendInput.ShiftEnterCustom"
  }
]
```

Збережіть файл і перезапустіть Windows Terminal або відкрийте нову вкладку.
