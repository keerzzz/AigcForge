Команда `aigcfroge serve` запускає сервер HTTP без графічного інтерфейсу, який надає ендпоінт OpenAPI, що його може використовувати клієнт aigcfroge.

---

### Використання

```bash
aigcfroge serve [--port <number>] [--hostname <string>] [--cors <origin>]
```

#### Опції

| Прапорець        | Опис                                        | За замовчуванням |
| --------------- | ----------------------------------- | ---------------- |
| `--port`        | Порт для прослуховування                    | `4096`           |
| `--hostname`    | Ім'я хоста для прослуховування              | `127.0.0.1`      |
| `--mdns`        | Увімкнути виявлення через mDNS              | `false`          |
| `--mdns-domain` | Власне доменне ім'я для служби mDNS         | `aigcfroge.local` |
| `--cors`        | Додаткові джерела браузера, які дозволено   | `[]`             |

`--cors` можна передавати кілька разів:

```bash
aigcfroge serve --cors http://localhost:5173 --cors https://app.example.com
```

---

### Автентифікація

Встановіть `AIGCFROGE_SERVER_PASSWORD`, щоб захистити сервер за допомогою базової автентифікації HTTP. Ім'я користувача за замовчуванням — `aigcfroge`; або встановіть `AIGCFROGE_SERVER_USERNAME`, щоб перевизначити його. Це стосується як `aigcfroge serve`, так і `aigcfroge web`.

```bash
AIGCFROGE_SERVER_PASSWORD=your-password aigcfroge serve
```

---

### Як це працює

Коли ви запускаєте `aigcfroge`, він запускає TUI та сервер. TUI є клієнтом, який спілкується із сервером. Сервер надає ендпоінт зі специфікацією OpenAPI 3.1. Цей ендпоінт також використовується для генерації [SDK](/docs/sdk).

:::tip
Використовуйте сервер aigcfroge, щоб взаємодіяти з aigcfroge програмно.
:::

Така архітектура дозволяє aigcfroge підтримувати кількох клієнтів і дає вам змогу взаємодіяти з aigcfroge програмно.

Ви можете запустити `aigcfroge serve`, щоб розпочати окремий сервер. Якщо у вас запущено TUI aigcfroge, `aigcfroge serve` запустить новий сервер.

---

#### Підключення до наявного сервера

Коли ви запускаєте TUI, він випадково призначає порт та ім'я хоста. Натомість ви можете передати [прапорці](/docs/cli) `--hostname` та `--port`. Потім використайте їх, щоб підключитися до його сервера.

Ендпоінт [`/tui`](#tui) можна використовувати для керування TUI через сервер. Наприклад, ви можете попередньо заповнити або запустити запит. Цю схему використовують плагіни Aigcfroge для [IDE](/docs/ide).

## Специфікація

Сервер публікує специфікацію OpenAPI 3.1, яку можна переглянути за адресою:

```
http://<hostname>:<port>/doc
```

Наприклад, `http://localhost:4096/doc`. Використовуйте специфікацію, щоб генерувати клієнтів або переглядати типи запитів і відповідей. Також її можна переглянути у Swagger explorer.

### Файли

| Метод | Шлях                      | Опис                                     | Відповідь                                                                                      |
| ------ | ------------------------ | ---------------------------------- | ------------------------------------------------------------------------------------------- |
| `GET`  | `/find?pattern=<pat>`    | Пошук тексту у файлах                    | Масив об'єктів збігів із полями `path`, `lines`, `line_number`, `absolute_offset`, `submatches` |

| `GET`  | `/find/symbol?query=<q>` | Пошук символів робочого простору         | <a href={typesUrl}><code>Symbol[]</code></a>                                                |

| `GET`  | `/file/content?path=<p>` | Прочитати файл                           | <a href={typesUrl}><code>FileContent</code></a>                                             |
| `GET`  | `/file/status`           | Отримати статус відстежуваних файлів     | <a href={typesUrl}><code>File[]</code></a>                                                  |

#### Параметри запиту `/find/file`

- `query` (обов'язковий) — рядок пошуку (нечіткий збіг)
- `type` (необов'язковий) — обмежити результати значеннями `"file"` або `"directory"`
- `directory` (необов'язковий) — перевизначити корінь проєкту для пошуку
- `limit` (необов'язковий) — максимальна кількість результатів (1–200)
- `dirs` (необов'язковий) — застарілий прапорець (`"false"` повертає лише файли)
