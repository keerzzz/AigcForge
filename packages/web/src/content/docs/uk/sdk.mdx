SDK aigcfroge для JS/TS надає типобезпечний клієнт для взаємодії із сервером. Використовуйте його для створення інтеграцій та програмного керування aigcfroge.

[Дізнайтеся більше](/docs/server) про те, як працює сервер. Приклади шукайте в [проєктах](/docs/ecosystem#projects), створених спільнотою.

---

## Встановлення

Встановіть SDK з npm:

```bash
npm install @aigcfroge/sdk
```

---

## Створення клієнта

Створіть екземпляр aigcfroge:

```javascript
import { createAigcfroge } from "@aigcfroge/sdk"

const { client } = await createAigcfroge()
```

Це запускає і сервер, і клієнт

#### Параметри

| Параметр     | Тип          | Опис                                         | За замовчуванням |
| ------------ | ------------ | -------------------------------------------- | ---------------- |
| `hostname`   | `string`     | Ім'я хоста сервера                           | `127.0.0.1`      |
| `port`       | `number`     | Порт сервера                                 | `4096`           |
| `signal`     | `AbortSignal`| Сигнал переривання для скасування            | `undefined`      |
| `timeout`    | `number`     | Час очікування в мс для запуску сервера      | `5000`           |
| `config`     | `Config`     | Об'єкт конфігурації                          | `{}`             |

## Конфігурація

Ви можете передати об'єкт конфігурації, щоб налаштувати поведінку. Екземпляр, як і раніше, читає ваш `aigcfroge.json`, але ви можете перевизначити або додати конфігурацію безпосередньо:

```javascript
import { createAigcfroge } from "@aigcfroge/sdk"

const aigcfroge = await createAigcfroge({
  hostname: "127.0.0.1",
  port: 4096,
  config: {
    model: "anthropic/claude-3-5-sonnet-20241022",
  },
})

console.log(`Server running at ${aigcfroge.server.url}`)

aigcfroge.server.close()
```

## Лише клієнт

Якщо у вас уже запущено екземпляр aigcfroge, ви можете створити екземпляр клієнта, щоб підключитися до нього:

```javascript
import { createAigcfrogeClient } from "@aigcfroge/sdk"

const client = createAigcfrogeClient({
  baseUrl: "http://localhost:4096",
})
```

#### Параметри

| Параметр         | Тип         | Опис                                        | За замовчуванням      |
| ---------------- | ----------- | ------------------------------------------- | --------------------- |
| `baseUrl`        | `string`    | URL сервера                                 | `http://localhost:4096` |
| `fetch`          | `function`  | Власна реалізація fetch                     | `globalThis.fetch`    |
| `parseAs`        | `string`    | Метод розбору відповіді                     | `auto`                |
| `responseStyle`  | `string`    | Стиль повернення: `data` або `fields`       | `fields`              |
| `throwOnError`   | `boolean`   | Викидати помилки замість повернення         | `false`               |

```typescript
try {
  await client.session.get({ path: { id: "invalid-id" } })
} catch (error) {
  console.error("Failed to get session:", (error as Error).message)
}
```

## Структурований вивід

Ви можете запитати у моделі структурований JSON-вивід, указавши `format` із JSON-схемою. Модель використає інструмент `StructuredOutput`, щоб повернути валідований JSON, що відповідає вашій схемі.

### Базове використання

```typescript
const result = await client.session.prompt({
  path: { id: sessionId },
  body: {
    parts: [{ type: "text", text: "Research Anthropic and provide company info" }],
    format: {
      type: "json_schema",
      schema: {
        type: "object",
        properties: {
          company: { type: "string", description: "Company name" },
          founded: { type: "number", description: "Year founded" },
          products: {
            type: "array",
            items: { type: "string" },
            description: "Main products",
          },
        },
        required: ["company", "founded"],
      },
    },
  },
})

// Access the structured output
console.log(result.data.info.structured_output)
// { company: "Anthropic", founded: 2021, products: ["Claude", "Claude API"] }
```

### Типи форматів виводу

| Тип            | Опис                                                     |
| -------------- | -------------------------------------------------------- |
| `text`         | За замовчуванням. Стандартна текстова відповідь (без структурованого виводу) |
| `json_schema`  | Повертає валідований JSON, що відповідає наданій схемі   |

### Формат JSON-схеми

Під час використання `type: 'json_schema'` надайте:

| Поле           | Тип            | Опис                                                      |
| -------------- | -------------- | --------------------------------------------------------- |
| `type`         | `'json_schema'`| Обов'язково. Задає режим JSON-схеми                      |
| `schema`       | `object`       | Обов'язково. Об'єкт JSON-схеми, що визначає структуру виводу |
| `retryCount`   | `number`       | Необов'язково. Кількість повторних спроб валідації (за замовчуванням: 2) |

### Обробка помилок

Якщо моделі не вдасться створити коректний структурований вивід після всіх повторних спроб, відповідь міститиме `StructuredOutputError`:

```typescript
if (result.data.info.error?.name === "StructuredOutputError") {
  console.error("Failed to produce structured output:", result.data.info.error.message)
  console.error("Attempts:", result.data.info.error.retries)
}
```

### Найкращі практики

1. **Надавайте чіткі описи** у властивостях схеми, щоб допомогти моделі зрозуміти, які дані потрібно витягти
2. **Використовуйте `required`**, щоб указати, які поля мають бути присутні
3. **Тримайте схеми зосередженими** — складні вкладені схеми моделі може бути важче заповнити правильно
4. **Встановлюйте відповідний `retryCount`** — збільшуйте для складних схем, зменшуйте для простих

#### Приклади

```javascript
// Create and manage sessions
const session = await client.session.create({
  body: { title: "My session" },
})

const sessions = await client.session.list()

// Send a prompt message
const result = await client.session.prompt({
  path: { id: session.id },
  body: {
    model: { providerID: "anthropic", modelID: "claude-3-5-sonnet-20241022" },
    parts: [{ type: "text", text: "Hello!" }],
  },
})

// Inject context without triggering AI response (useful for plugins)
await client.session.prompt({
  path: { id: session.id },
  body: {
    noReply: true,
    parts: [{ type: "text", text: "You are a helpful assistant." }],
  },
})
```

### Files

| Метод                             | Опис                                | Відповідь                                                                                 |
| --------------------------------- | ----------------------------------- | ----------------------------------------------------------------------------------------- |
| `find.text({ query })`            | Пошук тексту у файлах               | Масив об'єктів збігів із полями `path`, `lines`, `line_number`, `absolute_offset`, `submatches` |
| `find.files({ query })`           | Пошук файлів і каталогів за назвою  | `string[]` (шляхи)                                                                        |
| `find.symbols({ query })`         | Пошук символів робочої області      | <a href={typesUrl}><code>Symbol[]</code></a>                                              |
| `file.read({ query })`            | Прочитати файл                      | `{ type: "raw" \| "patch", content: string }`                                             |
| `file.status({ query? })`         | Отримати статус відстежуваних файлів | <a href={typesUrl}><code>File[]</code></a>                                                |

`find.files` підтримує кілька необов'язкових полів запиту:

- `type`: `"file"` або `"directory"`
- `directory`: перевизначте корінь проєкту для пошуку
- `limit`: максимальна кількість результатів (1–200)

---

#### Приклади

```javascript
// Search and read files
const textResults = await client.find.text({
  query: { pattern: "function.*aigcfroge" },
})

const files = await client.find.files({
  query: { query: "*.ts", type: "file" },
})

const directories = await client.find.files({
  query: { query: "packages", type: "directory", limit: 20 },
})

const content = await client.file.read({
  query: { path: "src/index.ts" },
})
```
