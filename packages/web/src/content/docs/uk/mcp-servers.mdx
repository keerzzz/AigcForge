---
title: MCP-сервери
description: Додавайте локальні та віддалені інструменти MCP.
---

Ви можете додавати зовнішні інструменти до Aigcfroge за допомогою _Model Context Protocol_, або MCP. Aigcfroge підтримує як локальні, так і віддалені сервери.

Після додавання інструменти MCP автоматично стають доступними LLM разом із вбудованими інструментами.

---

#### Застереження

Коли ви використовуєте MCP-сервер, він додається до контексту. Це може швидко накопичуватися, якщо у вас багато інструментів. Тому ми рекомендуємо бути обережними з тим, які MCP-сервери ви використовуєте.

:::tip
MCP-сервери додаються до вашого контексту, тому будьте обережні з тим, які з них ви вмикаєте.
:::

Деякі MCP-сервери, як-от MCP-сервер GitHub, додають багато токенів і можуть легко перевищити ліміт контексту.

---

## Увімкнення

Ви можете визначити MCP-сервери у своїй [конфігурації Aigcfroge](https://aigcfroge.ai/docs/config/) у розділі `mcp`. Додайте кожен MCP з унікальною назвою. Ви можете посилатися на цей MCP за назвою, коли звертаєтесь до LLM.

```jsonc title="aigcfroge.jsonc" {6}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "mcp": {
    "name-of-mcp-server": {
      // ...
      "enabled": true,
    },
    "name-of-other-mcp-server": {
      // ...
    },
  },
}
```

Ви також можете вимкнути сервер, встановивши `enabled` у значення `false`. Це корисно, якщо ви хочете тимчасово вимкнути сервер, не видаляючи його з конфігурації.

---

### Перевизначення віддалених налаштувань за замовчуванням

Організації можуть надавати MCP-сервери за замовчуванням через свою кінцеву точку `.well-known/aigcfroge`. Ці сервери можуть бути вимкнені за замовчуванням, що дозволяє користувачам вмикати лише потрібні їм.

Щоб увімкнути конкретний сервер із віддаленої конфігурації вашої організації, додайте його до локальної конфігурації з `enabled: true`:

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "mcp": {
    "jira": {
      "type": "remote",
      "url": "https://jira.example.com/mcp",
      "enabled": true
    }
  }
}
```

Значення вашої локальної конфігурації перевизначають віддалені значення за замовчуванням. Докладніше див. [пріоритет конфігурації](/docs/config#precedence-order).

## Локальні

Додавайте локальні MCP-сервери, встановивши `type` у значення `"local"` в об'єкті MCP.

```jsonc title="aigcfroge.jsonc" {15}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "mcp": {
    "my-local-mcp-server": {
      "type": "local",
      // Or ["bun", "x", "my-mcp-command"]
      "command": ["npx", "-y", "my-mcp-command"],
      "enabled": true,
      "environment": {
        "MY_ENV_VAR": "my_env_var_value",
      },
    },
  },
}
```

Команда визначає, як запускається локальний MCP-сервер. Ви також можете передати список змінних середовища.

Наприклад, ось як додати тестовий MCP-сервер [`@modelcontextprotocol/server-everything`](https://www.npmjs.com/package/@modelcontextprotocol/server-everything).

```jsonc title="aigcfroge.jsonc"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "mcp": {
    "mcp_everything": {
      "type": "local",
      "command": ["npx", "-y", "@modelcontextprotocol/server-everything"],
    },
  },
}
```

А щоб використати його, я можу додати `use the mcp_everything tool` до своїх підказок.

```txt "mcp_everything"
use the mcp_everything tool to add the number 3 and 4
```

---

#### Параметри

Ось усі параметри для налаштування локального MCP-сервера.

| Параметр     | Тип     | Обов'язковий | Опис                                                                                       |
| ------------ | ------- | ------------ | ------------------------------------------------------------------------------------------ |
| `type`       | String  | Так          | Тип підключення MCP-сервера, має бути `"local"`.                                           |
| `command`    | Array   | Так          | Команда та аргументи для запуску MCP-сервера.                                              |
| `cwd`        | String  |              | Робочий каталог для процесу MCP-сервера. Відносні шляхи розв'язуються відносно робочого простору. |
| `environment` | Object |              | Змінні середовища, які встановлюються під час запуску сервера.                             |
| `enabled`    | Boolean |              | Увімкнути або вимкнути MCP-сервер під час запуску.                                         |
| `timeout`    | Number  |              | Таймаут у мс для отримання інструментів із MCP-сервера. За замовчуванням — 5000 (5 секунд). |

---

## Віддалені

Додавайте віддалені MCP-сервери, встановивши `type` у значення `"remote"`.

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "mcp": {
    "my-remote-mcp": {
      "type": "remote",
      "url": "https://my-mcp-server.com",
      "enabled": true,
      "headers": {
        "Authorization": "Bearer MY_API_KEY"
      }
    }
  }
}
```

`url` — це URL віддаленого MCP-сервера, а за допомогою параметра `headers` ви можете передати список заголовків.

---

#### Параметри

| Параметр | Тип     | Обов'язковий | Опис                                                                                        |
| -------- | ------- | ------------ | ------------------------------------------------------------------------------------------- |
| `type`   | String  | Так          | Тип підключення MCP-сервера, має бути `"remote"`.                                           |
| `url`    | String  | Так          | URL віддаленого MCP-сервера.                                                                |
| `enabled`| Boolean |              | Увімкнути або вимкнути MCP-сервер під час запуску.                                          |
| `headers`| Object  |              | Заголовки, які надсилаються разом із запитом.                                               |
| `oauth`  | Object  |              | Конфігурація автентифікації OAuth. Див. розділ [OAuth](#oauth) нижче.                       |
| `timeout`| Number  |              | Таймаут у мс для отримання інструментів із MCP-сервера. За замовчуванням — 5000 (5 секунд). |

---

## OAuth

Aigcfroge автоматично обробляє автентифікацію OAuth для віддалених MCP-серверів. Коли сервер вимагає автентифікації, Aigcfroge:

1. Виявить відповідь 401 і запустить процес OAuth
2. Використає **динамічну реєстрацію клієнта (RFC 7591)**, якщо вона підтримується сервером
3. Безпечно збереже токени для майбутніх запитів

---

### Автоматично

Для більшості MCP-серверів із підтримкою OAuth не потрібна спеціальна конфігурація. Просто налаштуйте віддалений сервер:

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "mcp": {
    "my-oauth-server": {
      "type": "remote",
      "url": "https://mcp.example.com/mcp"
    }
  }
}
```

Якщо сервер вимагає автентифікації, Aigcfroge запропонує вам автентифікуватися під час першої спроби його використання. Якщо ні, ви можете [вручну запустити процес](#authenticating) за допомогою `aigcfroge mcp auth <server-name>`.

---

### Попередньо зареєстровані

Якщо у вас є клієнтські облікові дані від провайдера MCP-сервера, ви можете налаштувати їх:

```json title="aigcfroge.json" {7-11}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "mcp": {
    "my-oauth-server": {
      "type": "remote",
      "url": "https://mcp.example.com/mcp",
      "oauth": {
        "clientId": "{env:MY_MCP_CLIENT_ID}",
        "clientSecret": "{env:MY_MCP_CLIENT_SECRET}",
        "scope": "tools:read tools:execute"
      }
    }
  }
}
```

---

### Автентифікація

Ви можете вручну запустити автентифікацію або керувати обліковими даними.

Автентифікуйтеся з конкретним MCP-сервером:

```bash
aigcfroge mcp auth my-oauth-server
```

Перелічіть усі MCP-сервери та їхній статус автентифікації:

```bash
aigcfroge mcp list
```

Видаліть збережені облікові дані:

```bash
aigcfroge mcp logout my-oauth-server
```

Команда `mcp auth` відкриє ваш браузер для авторизації. Після того, як ви авторизуєте, Aigcfroge безпечно збереже токени у `~/.local/share/aigcfroge/mcp-auth.json`.

---

#### Вимкнення OAuth

Якщо ви хочете вимкнути автоматичний OAuth для сервера (наприклад, для серверів, які натомість використовують API-ключі), встановіть `oauth` у значення `false`:

```json title="aigcfroge.json" {7}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "mcp": {
    "my-api-key-server": {
      "type": "remote",
      "url": "https://mcp.example.com/mcp",
      "oauth": false,
      "headers": {
        "Authorization": "Bearer {env:MY_API_KEY}"
      }
    }
  }
}
```

---

#### Параметри OAuth

| Параметр      | Тип             | Опис                                                                                |
| ------------- | --------------- | ----------------------------------------------------------------------------------- |
| `oauth`       | Object \| false | Об'єкт конфігурації OAuth або `false`, щоб вимкнути автоматичне визначення OAuth.   |
| `clientId`    | String          | Ідентифікатор клієнта OAuth. Якщо його не надано, буде спробувано динамічну реєстрацію клієнта. |
| `clientSecret`| String          | Секрет клієнта OAuth, якщо його вимагає сервер авторизації.                         |
| `scope`       | String          | Обсяги доступу OAuth, які запитуються під час авторизації.                          |

#### Налагодження

Якщо віддалений MCP-сервер не може автентифікуватися, ви можете діагностувати проблеми за допомогою:

```bash
# View auth status for all OAuth-capable servers
aigcfroge mcp auth list

# Debug connection and OAuth flow for a specific server
aigcfroge mcp debug my-oauth-server
```

Команда `mcp debug` показує поточний статус автентифікації, перевіряє HTTP-з'єднання та намагається виконати процес виявлення OAuth.

## Керування

Ваші MCP доступні як інструменти в Aigcfroge, поряд із вбудованими інструментами. Тож ви можете керувати ними через конфігурацію Aigcfroge, як і будь-яким іншим інструментом.

---

### Глобально

Це означає, що ви можете вмикати або вимикати їх глобально.

```json title="aigcfroge.json" {14}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "mcp": {
    "my-mcp-foo": {
      "type": "local",
      "command": ["bun", "x", "my-mcp-command-foo"]
    },
    "my-mcp-bar": {
      "type": "local",
      "command": ["bun", "x", "my-mcp-command-bar"]
    }
  },
  "tools": {
    "my-mcp-foo": false
  }
}
```

Ми також можемо використати glob-шаблон, щоб вимкнути всі відповідні MCP.

```json title="aigcfroge.json" {14}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "mcp": {
    "my-mcp-foo": {
      "type": "local",
      "command": ["bun", "x", "my-mcp-command-foo"]
    },
    "my-mcp-bar": {
      "type": "local",
      "command": ["bun", "x", "my-mcp-command-bar"]
    }
  },
  "tools": {
    "my-mcp*": false
  }
}
```

Тут ми використовуємо glob-шаблон `my-mcp*`, щоб вимкнути всі MCP.

---

### Для кожного агента

Якщо у вас велика кількість MCP-серверів, ви можете вмикати їх лише для окремих агентів і вимикати глобально. Щоб зробити це:

1. Вимкніть його як інструмент глобально.
2. У вашій [конфігурації агента](/docs/agents#tools) увімкніть MCP-сервер як інструмент.

```json title="aigcfroge.json" {11, 14-18}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "mcp": {
    "my-mcp": {
      "type": "local",
      "command": ["bun", "x", "my-mcp-command"],
      "enabled": true
    }
  },
  "tools": {
    "my-mcp*": false
  },
  "agent": {
    "my-agent": {
      "tools": {
        "my-mcp*": true
      }
    }
  }
}
```

---

#### Glob-шаблони

Glob-шаблон використовує прості regex-шаблони зіставлення:

- `*` збігається з нулем або більше будь-яких символів (наприклад, `"my-mcp*"` збігається з `my-mcp_search`, `my-mcp_list` тощо)
- `?` збігається рівно з одним символом
- Усі інші символи збігаються буквально

:::note
Інструменти MCP-сервера реєструються з назвою сервера як префіксом, тому, щоб вимкнути всі інструменти сервера, просто використайте:

```
"mymcpservername_*": false
```

:::

## Приклади

Нижче наведено приклади деяких поширених MCP-серверів. Ви можете надіслати PR, якщо хочете задокументувати інші сервери.

---

### Sentry

Додайте [MCP-сервер Sentry](https://mcp.sentry.dev), щоб взаємодіяти зі своїми проєктами та проблемами Sentry.

```json title="aigcfroge.json" {4-8}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "mcp": {
    "sentry": {
      "type": "remote",
      "url": "https://mcp.sentry.dev/mcp",
      "oauth": {}
    }
  }
}
```

Після додавання конфігурації автентифікуйтеся з Sentry:

```bash
aigcfroge mcp auth sentry
```

Це відкриє вікно браузера, щоб завершити процес OAuth і підключити Aigcfroge до вашого облікового запису Sentry.

Після автентифікації ви можете використовувати інструменти Sentry у своїх підказках, щоб запитувати проблеми, проєкти та дані про помилки.

```txt "use sentry"
Show me the latest unresolved issues in my project. use sentry
```

---

### Context7

Додайте [MCP-сервер Context7](https://github.com/upstash/context7), щоб шукати в документації.

```json title="aigcfroge.json" {4-7}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "mcp": {
    "context7": {
      "type": "remote",
      "url": "https://mcp.context7.com/mcp"
    }
  }
}
```

Якщо ви зареєстрували безкоштовний обліковий запис, ви можете використовувати свій API-ключ і отримати вищі ліміти запитів.

```json title="aigcfroge.json" {7-9}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "mcp": {
    "context7": {
      "type": "remote",
      "url": "https://mcp.context7.com/mcp",
      "headers": {
        "CONTEXT7_API_KEY": "{env:CONTEXT7_API_KEY}"
      }
    }
  }
}
```

Тут ми припускаємо, що у вас встановлено змінну середовища `CONTEXT7_API_KEY`.

Додайте `use context7` до своїх підказок, щоб використовувати MCP-сервер Context7.

```txt "use context7"
Configure a Cloudflare Worker script to cache JSON API responses for five minutes. use context7
```

Крім того, ви можете додати щось подібне до свого файлу [AGENTS.md](/docs/rules/).

```md title="AGENTS.md"
When you need to search docs, use `context7` tools.
```

---

### Grep by Vercel

Додайте MCP-сервер [Grep by Vercel](https://grep.app), щоб шукати фрагменти коду на GitHub.

```json title="aigcfroge.json" {4-7}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "mcp": {
    "gh_grep": {
      "type": "remote",
      "url": "https://mcp.grep.app"
    }
  }
}
```

Оскільки ми назвали наш MCP-сервер `gh_grep`, ви можете додати `use the gh_grep tool` до своїх підказок, щоб агент використовував його.

```txt "use the gh_grep tool"
What's the right way to set a custom domain in an SST Astro component? use the gh_grep tool
```

Крім того, ви можете додати щось подібне до свого файлу [AGENTS.md](/docs/rules/).

```md title="AGENTS.md"
If you are unsure how to do something, use `gh_grep` to search code examples from GitHub.
```
