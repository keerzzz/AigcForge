Aigcfroge використовує [AI SDK](https://ai-sdk.dev/) і [Models.dev](https://models.dev), щоб підтримувати **понад 75 провайдерів LLM**, а також підтримує запуск локальних моделей.

---

## Провайдери

Найпопулярніші провайдери попередньо завантажуються за замовчуванням. Якщо ви додали облікові дані провайдера через команду `/connect`, вони будуть доступні, коли ви запустите Aigcfroge.

Дізнайтеся більше про [провайдерів](/docs/providers).

---

## Вибір моделі

Після налаштування провайдера ви можете вибрати потрібну модель, ввівши:

```bash frame="none"
/models
```

## Встановлення типової моделі

Щоб встановити одну з них як типову модель, ви можете задати ключ `model` у конфігурації Aigcfroge.

```json title="aigcfroge.json" {3}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "model": "lmstudio/google/gemma-3n-e4b"
}
```

Повний ідентифікатор має формат `provider_id/model_id`. Наприклад, якщо ви використовуєте [Aigcfroge Zen](/docs/zen), для GPT 5.1 Codex ви використали б `aigcfroge/gpt-5.1-codex`.

Якщо ви налаштували [власного провайдера](/docs/providers#custom), то `provider_id` — це ключ із частини `provider` вашої конфігурації, а `model_id` — це ключ із `provider.models`.

## Налаштування моделей

Ви можете глобально налаштувати параметри моделі через конфігурацію.

```jsonc title="aigcfroge.jsonc" {7-12,19-24}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "provider": {
    "openai": {
      "models": {
        "gpt-5": {
          "options": {
            "reasoningEffort": "high",
            "textVerbosity": "low",
            "reasoningSummary": "auto",
            "include": ["reasoning.encrypted_content"],
          },
        },
      },
    },
    "anthropic": {
      "models": {
        "claude-sonnet-4-5-20250929": {
          "options": {
            "thinking": {
              "type": "enabled",
              "budgetTokens": 16000,
            },
          },
        },
      },
    },
  },
}
```

Тут ми налаштовуємо глобальні параметри для двох вбудованих моделей: `gpt-5` під час доступу через провайдера `openai` та `claude-sonnet-4-20250514` під час доступу через провайдера `anthropic`.
Назви вбудованих провайдерів і моделей можна знайти на [Models.dev](https://models.dev).

Ви також можете налаштувати ці параметри для будь-яких агентів, яких використовуєте. Конфігурація агента перевизначає будь-які глобальні параметри. [Дізнайтеся більше](/docs/agents/#additional).

Ви також можете визначити власні варіанти, які розширюють вбудовані. Варіанти дозволяють налаштувати різні параметри для однієї моделі без створення дублікатів записів:

```jsonc title="aigcfroge.jsonc" {6-21}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "provider": {
    "aigcfroge": {
      "models": {
        "gpt-5": {
          "variants": {
            "high": {
              "reasoningEffort": "high",
              "textVerbosity": "low",
              "reasoningSummary": "auto",
            },
            "low": {
              "reasoningEffort": "low",
              "textVerbosity": "low",
              "reasoningSummary": "auto",
            },
          },
        },
      },
    },
  },
}
```

## Варіанти

Багато моделей підтримують кілька варіантів із різними конфігураціями. Aigcfroge постачається з вбудованими типовими варіантами для популярних провайдерів.

### Вбудовані варіанти

Aigcfroge постачається з типовими варіантами для багатьох провайдерів:

**Anthropic**:

- `high` — високий бюджет роздумів (за замовчуванням)
- `max` — максимальний бюджет роздумів

**OpenAI**:

Залежить від моделі, але приблизно:

- `none` — без міркувань
- `minimal` — мінімальні зусилля міркувань
- `low` — низькі зусилля міркувань
- `medium` — середні зусилля міркувань
- `high` — високі зусилля міркувань
- `xhigh` — надзвичайно високі зусилля міркувань

**Google**:

- `low` — нижчий бюджет зусиль/токенів
- `high` — вищий бюджет зусиль/токенів

:::tip
Цей список не вичерпний. Багато інших провайдерів також мають вбудовані типові значення.
:::

### Власні варіанти

Ви можете перевизначити наявні варіанти або додати власні:

```jsonc title="aigcfroge.jsonc" {7-18}
{
  "$schema": "https://aigcfroge.ai/config.json",
  "provider": {
    "openai": {
      "models": {
        "gpt-5": {
          "variants": {
            "thinking": {
              "reasoningEffort": "high",
              "textVerbosity": "low",
            },
            "fast": {
              "disabled": true,
            },
          },
        },
      },
    },
  },
}
```

### Циклічне перемикання варіантів

Використовуйте клавіатурне скорочення `variant_cycle`, щоб швидко перемикатися між варіантами. [Дізнайтеся більше](/docs/keybinds).

## Завантаження моделей

Під час запуску Aigcfroge шукає моделі в такому порядку пріоритету:

1. Прапорець командного рядка `--model` або `-m`. Формат такий самий, як у файлі конфігурації: `provider_id/model_id`.

2. Список моделей у конфігурації Aigcfroge.

   ```json title="aigcfroge.json"
   {
     "$schema": "https://aigcfroge.ai/config.json",
     "model": "anthropic/claude-sonnet-4-20250514"
   }
   ```

   Тут формат — `provider/model`.

3. Остання використана модель.

4. Перша модель за внутрішнім пріоритетом.
