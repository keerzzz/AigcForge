---
title: Посилання
description: Додавайте локальні каталоги та Git-репозиторії як посилання проєкту.
---

Посилання надають Aigcfroge доступ до каталогів поза поточним проєктом. Використовуйте їх, щоб під час роботи мати доступ до документації, спільних бібліотек, прикладів або іншого репозиторію.

Посилання налаштовуються за псевдонімом у файлах `aigcfroge.json` або `aigcfroge.jsonc`.

```jsonc title="aigcfroge.jsonc"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "references": {
    "docs": {
      "path": "../product-docs",
      "description": "Use for product behavior and documentation conventions",
    },
    "sdk": {
      "repository": "keerzzz/AigcForge-sdk-js",
      "branch": "main",
      "description": "Use for JavaScript SDK implementation details",
    },
  },
}
```

---

## Локальні каталоги

Використовуйте `path`, щоб посилатися на локальний каталог.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "docs": {
      "path": "../docs",
    },
  },
}
```

Шляхи можуть бути:

- Відносними до файлу конфігурації, який визначає посилання
- Абсолютними, наприклад `/home/user/docs`
- Відносними до вашого домашнього каталогу, наприклад `~/docs`

Також можна використати скорочення у вигляді рядка:

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "docs": "../docs",
  },
}
```

---

## Git-репозиторії

Використовуйте `repository`, щоб посилатися на Git-репозиторій. Aigcfroge матеріалізує репозиторій у своєму локальному кеші репозиторіїв і робить вихідний код доступним як каталог посилання.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "effect": {
      "repository": "Effect-TS/effect",
      "branch": "main",
    },
  },
}
```

`repository` приймає Git-URL, посилання host/path та скорочення GitHub `owner/repo`. Необов'язкове поле `branch` вибирає гілку або реф. Без `branch` Aigcfroge використовує гілку репозиторію за замовчуванням.

Ви можете використати скорочення у вигляді рядка, якщо вам не потрібні гілка, опис чи інші параметри:

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "effect": "Effect-TS/effect",
  },
}
```

:::note
Git-посилання оновлюються асинхронно. Щойно налаштований репозиторій може потребувати деякого часу, щоб завершити клонування або оновлення.
:::

## Опис використання

Додайте `description`, щоб пояснити, коли агенту слід використовувати посилання.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "design-system": {
      "path": "../design-system",
      "description": "Use when implementing UI components or design tokens",
    },
  },
}
```

Aigcfroge включає посилання з описами в контекст агента. Опис має бути коротким і достатньо конкретним, щоб розрізняти посилання зі схожим вмістом. Посилання без опису залишаються доступними через автодоповнення та пряме використання, але не рекламуються агентам.

---

## Приховування записів автодоповнення

Встановіть `hidden` як `true`, щоб виключити посилання з автодоповнення `@` у TUI.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "internal": {
      "path": "../internal",
      "description": "Use for internal implementation details",
      "hidden": true,
    },
  },
}
```

`hidden` впливає лише на автодоповнення. Приховане посилання з описом залишається включеним у контекст агента.

---

## Використання посилань

Налаштовані посилання з'являються в автодоповненні `@` у TUI. Введіть `@alias`, щоб прикріпити корінь посилання, або `@alias/`, щоб шукати файли всередині нього.

```text
Compare this implementation with @sdk/src/client.ts
```

Агенти також отримують у свій системний контекст розв'язані шляхи та описи налаштованих посилань, що мають опис, тож вони можуть переглянути посилання, коли це доречно, без ручного прикріплення.

Aigcfroge автоматично дозволяє каталоги посилань через свій кордон дозволів зовнішніх каталогів. Звичайні дозволи інструментів продовжують діяти; наприклад, агент, який не може редагувати файли, не отримує доступу до редагування лише тому, що каталог налаштовано як посилання.

---

## Поля конфігурації

| Поле          | Локальний | Git | Опис                                                  |
| ------------- | --------- | --- | ----------------------------------------------------- |
| `path`        | Так       | Ні  | Локальний каталог посилання                           |
| `repository`  | Ні        | Так | Git-URL, host/path або значення `owner/repo` GitHub   |
| `branch`      | Ні        | Так | Необов'язкова гілка або реф Git                       |
| `description` | Так       | Так | Вказівки, що описують, коли використовувати посилання |
| `hidden`      | Так       | Так | Приховати посилання з автодоповнення `@` у TUI        |

Псевдоніми посилань не можуть бути порожніми або містити `/`, пробіли, зворотні лапки чи коми.
