---
title: 참조
description: 로컬 디렉토리와 Git repository를 프로젝트 참조로 추가합니다.
---

참조는 Aigcfroge가 현재 프로젝트 외부의 디렉토리에 액세스할 수 있게 해줍니다. 작업 중 문서, 공유 라이브러리, 예제 또는 다른 repository를 사용할 수 있도록 만들 때 활용하세요.

참조는 `aigcfroge.json` 또는 `aigcfroge.jsonc`에서 alias로 구성합니다.

```jsonc title="aigcfroge.jsonc"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "references": {
    "docs": {
      "path": "../product-docs",
      "description": "Use for product behavior and documentation conventions",
    },
    "sdk": {
      "repository": "keerzzz/AigcForge-sdk-js",
      "branch": "main",
      "description": "Use for JavaScript SDK implementation details",
    },
  },
}
```

---

## 로컬 디렉토리

로컬 디렉토리를 참조하려면 `path`를 사용하세요.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "docs": {
      "path": "../docs",
    },
  },
}
```

경로는 다음이 될 수 있습니다:

- 참조를 정의하는 config 파일 기준 상대 경로
- `/home/user/docs` 같은 절대 경로
- `~/docs` 같은 홈 디렉토리 기준 경로

문자열 축약 표기로도 사용할 수 있습니다:

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "docs": "../docs",
  },
}
```

## Git repository

Git repository를 참조하려면 `repository`를 사용하세요. Aigcfroge는 repository를 로컬 repository 캐시에 구체화하고 checkout된 소스를 참조 디렉토리로 사용할 수 있게 합니다.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "effect": {
      "repository": "Effect-TS/effect",
      "branch": "main",
    },
  },
}
```

`repository`는 Git URL, host/path 참조, GitHub `owner/repo` 축약 표기를 허용합니다. 선택적 `branch` 필드로 branch 또는 ref를 선택합니다. `branch`가 없으면 Aigcfroge는 repository의 기본 branch를 사용합니다.

branch, description 또는 기타 옵션이 필요하지 않으면 문자열 축약 표기를 사용할 수 있습니다:

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "effect": "Effect-TS/effect",
  },
}
```

:::note
Git 참조는 비동기적으로 새로고침됩니다. 새로 구성한 repository는 clone 또는 업데이트를 마치는 데 잠시 걸릴 수 있습니다.
:::

## 사용 용도 설명

agent가 언제 참조를 사용해야 하는지 설명하려면 `description`을 추가하세요.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "design-system": {
      "path": "../design-system",
      "description": "Use when implementing UI components or design tokens",
    },
  },
}
```

Aigcfroge는 description이 있는 참조를 agent context에 포함합니다. Description은 비슷한 내용의 참조를 구분할 수 있을 만큼 짧고 구체적이어야 합니다. Description이 없는 참조는 autocomplete와 직접 사용으로 계속 사용할 수 있지만, agent에게는 알리지 않습니다.

---

## autocomplete 항목 숨기기

TUI의 `@` autocomplete에서 참조를 제외하려면 `hidden`을 `true`로 설정하세요.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "internal": {
      "path": "../internal",
      "description": "Use for internal implementation details",
      "hidden": true,
    },
  },
}
```

`hidden`은 autocomplete에만 영향을 줍니다. description이 있는 숨겨진 참조는 agent context에 계속 포함됩니다.

---

## 참조 사용

구성된 참조는 TUI `@` autocomplete에 나타납니다. `@alias`를 입력하면 참조 루트를 첨부하고, `@alias/`를 입력하면 그 안의 파일을 검색합니다.

```text
Compare this implementation with @sdk/src/client.ts
```

agent는 또한 시스템 context에서 description이 있는 구성된 참조의 해석된 경로와 description을 받으므로, 관련이 있을 때 직접 첨부하지 않아도 참조를 확인할 수 있습니다.

Aigcfroge는 참조 디렉토리를 external-directory 권한 경계를 통해 자동으로 허용합니다. 일반 tool 권한은 여전히 적용됩니다. 예를 들어, 파일 편집이 불가능한 agent는 디렉토리가 참조로 구성되었다고 해서 편집 권한을 얻지 않습니다.

## 구성 필드

| 필드 | 로컬 | Git | 설명 |
| ------------- | ----- | --- | ------------------------------------------------ |
| `path` | 예 | 아니요 | 로컬 참조 디렉토리 |
| `repository` | 아니요 | 예 | Git URL, host/path 또는 GitHub `owner/repo` 값 |
| `branch` | 아니요 | 예 | 선택적 Git branch 또는 ref |
| `description` | 예 | 예 | 참조를 언제 사용할지 설명하는 지침 |
| `hidden` | 예 | 예 | TUI `@` autocomplete에서 참조 숨김 |

참조 alias는 비어 있을 수 없으며 `/`, 공백, 백틱 또는 쉼표를 포함할 수 없습니다.
