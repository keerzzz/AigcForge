title: Ссылки
description: Добавляйте локальные каталоги и репозитории Git как ссылки на проект.
---

Ссылки дают Aigcfroge доступ к каталогам за пределами текущего проекта. Используйте их, чтобы сделать документацию, общие библиотеки, примеры или другой репозиторий доступными во время работы.

Ссылки настраиваются по псевдониму в `aigcfroge.json` или `aigcfroge.jsonc`.

```jsonc title="aigcfroge.jsonc"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "references": {
    "docs": {
      "path": "../product-docs",
      "description": "Use for product behavior and documentation conventions",
    },
    "sdk": {
      "repository": "keerzzz/AigcForge-sdk-js",
      "branch": "main",
      "description": "Use for JavaScript SDK implementation details",
    },
  },
}
```

---

## Локальные каталоги

Используйте `path` для ссылки на локальный каталог.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "docs": {
      "path": "../docs",
    },
  },
}
```

Пути могут быть:

- Относительными к файлу конфигурации, который определяет ссылку
- Абсолютными, например `/home/user/docs`
- Относительными к вашему домашнему каталогу, например `~/docs`

Вы также можете использовать строковое сокращение:

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "docs": "../docs",
  },
}
```

## Репозитории Git

Используйте `repository` для ссылки на репозиторий Git. Aigcfroge материализует репозиторий в своем локальном кэше репозиториев и делает извлеченный исходный код доступным в качестве каталога ссылок.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "effect": {
      "repository": "Effect-TS/effect",
      "branch": "main",
    },
  },
}
```

`repository` принимает URL-адреса Git, ссылки хост/путь и сокращение GitHub `owner/repo`. Необязательное поле `branch` выбирает ветку или ссылку. Без `branch` Aigcfroge использует ветку по умолчанию репозитория.

Вы можете использовать строковое сокращение, если вам не нужна ветка, описание или другие параметры:

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "effect": "Effect-TS/effect",
  },
}
```

:::note
Ссылки на Git обновляются асинхронно. Недавно настроенному репозиторию может потребоваться некоторое время, чтобы завершить клонирование или обновление.
:::

## Описание использования

Добавьте `description`, чтобы объяснить, когда агент должен использовать ссылку.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "design-system": {
      "path": "../design-system",
      "description": "Use when implementing UI components or design tokens",
    },
  },
}
```

Aigcfroge включает ссылки с описаниями в контекст агента. Описания должны быть короткими и достаточно конкретными, чтобы различать ссылки с похожим содержимым. Ссылки без описаний остаются доступными через автодополнение и прямое использование, но не рекламируются агентам.

---

## Скрытие записей автодополнения

Установите для `hidden` значение `true`, чтобы исключить ссылку из автодополнения `@` в TUI.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "internal": {
      "path": "../internal",
      "description": "Use for internal implementation details",
      "hidden": true,
    },
  },
}
```

`hidden` влияет только на автодополнение. Скрытая ссылка с описанием остается включенной в контекст агента.

---

## Использование ссылок

Настроенные ссылки появляются в автодополнении `@` в TUI. Введите `@alias`, чтобы прикрепить корень ссылки, или `@alias/`, чтобы искать файлы внутри нее.

```text
Compare this implementation with @sdk/src/client.ts
```

Агенты также получают разрешенные пути и описания настроенных ссылок, имеющих описания в их системном контексте, чтобы они могли проверить ссылку, когда это уместно, без необходимости прикреплять ее вручную.

Aigcfroge автоматически разрешает каталоги ссылок через свою границу разрешений внешних каталогов. Обычные разрешения инструментов по-прежнему применяются; например, агент, который не может редактировать файлы, не получает доступ к редактированию только потому, что каталог настроен как ссылка.

## Поля конфигурации

| Поле          | Локальный | Git | Описание                                              |
| ------------- | --------- | --- | ------------------------------------------------------ |
| `path`        | Да        | Нет | Локальный каталог ссылки                               |
| `repository`  | Нет       | Да  | URL-адрес Git, хост/путь или значение GitHub `owner/repo` |
| `branch`      | Нет       | Да  | Необязательная ветка Git или ссылка                    |
| `description` | Да        | Да  | Инструкции, описывающие, когда использовать ссылку     |
| `hidden`      | Да        | Да  | Скрыть ссылку из автодополнения `@` в TUI              |

Псевдонимы ссылок не могут быть пустыми или содержать `/`, пробелы, обратные кавычки или запятые.
