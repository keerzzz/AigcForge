---
title: Политики
description: Управляйте тем, какие настроенные ресурсы Aigcfroge может использовать.
---

Политики управляют тем, может ли Aigcfroge выполнять действие над именованным ресурсом. Эта функция является экспериментальной и настраивается с помощью массива `experimental.policies` в `aigcfroge.json`.

Политики отличаются от [разрешений](/docs/permissions). Разрешения управляют тем, что инструменты могут делать во время сеанса, тогда как политики управляют тем, может ли Aigcfroge использовать такой ресурс, как поставщик LLM.

---

## Конфигурация

Каждый оператор политики имеет три поля:

- `effect` — либо `"allow"`, либо `"deny"`.
- `action` — управляемая операция.
- `resource` — идентификатор ресурса или шаблон с подстановочными знаками, к которому применяется оператор.

Например, запретите использование поставщика `openai`:

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "experimental": {
    "policies": [
      {
        "effect": "deny",
        "action": "provider.use",
        "resource": "openai"
      }
    ]
  }
}
```

Поставщик, запрещенный политикой, недоступен для выбора или использования модели, даже если у него есть учетные данные или он правильно настроен.

---

## Доступные политики

Aigcfroge в настоящее время поддерживает одно действие политики:

| Действие      | Ресурс                           | Описание                                              |
| ------------- | -------------------------------- | ----------------------------------------------------- |
| `provider.use` | Идентификатор поставщика, например `openai` | Разрешить или запретить использование поставщика LLM. |

В будущем могут быть добавлены другие действия политик.

---

## Сопоставление

Поле `resource` поддерживает сопоставление с подстановочными знаками. Используйте `*` для сопоставления с нулем или более символов и `?` для сопоставления с одним символом.

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "experimental": {
    "policies": [
      {
        "effect": "deny",
        "action": "provider.use",
        "resource": "company-*"
      }
    ]
  }
}
```

Это запрещает таких поставщиков, как `company-us` и `company-eu`.

---

## Порядок правил

Когда совпадают несколько операторов, побеждает последний совпадающий оператор. Помещайте общие правила первыми, а затем более конкретные исключения после них.

Например, разрешите только Anthropic:

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "experimental": {
    "policies": [
      {
        "effect": "deny",
        "action": "provider.use",
        "resource": "*"
      },
      {
        "effect": "allow",
        "action": "provider.use",
        "resource": "anthropic"
      }
    ]
  }
}
```

Если политика не соответствует поставщику, использование поставщика разрешено по умолчанию.

Политики могут быть заданы как в вашей глобальной конфигурации, так и в конфигурации проекта. Если политики из обоих мест соответствуют одному и тому же поставщику, ваша глобальная политика имеет приоритет над политикой проекта. Это не позволяет репозиторию повторно включить поставщика, которого вы запрещаете глобально.

## Списки поставщиков

При управлении доступом к поставщикам используйте политики вместо устаревших настроек `disabled_providers` и `enabled_providers`.

Чтобы заменить `disabled_providers`:

```json title="aigcfroge.json"
{
  "experimental": {
    "policies": [
      { "effect": "deny", "action": "provider.use", "resource": "openai" },
      { "effect": "deny", "action": "provider.use", "resource": "google" }
    ]
  }
}
```

Чтобы заменить `enabled_providers`, сначала запретите всех поставщиков, а затем разрешите выбранных поставщиков после этого:

```json title="aigcfroge.json"
{
  "experimental": {
    "policies": [
      { "effect": "deny", "action": "provider.use", "resource": "*" },
      { "effect": "allow", "action": "provider.use", "resource": "anthropic" },
      { "effect": "allow", "action": "provider.use", "resource": "openai" }
    ]
  }
}
```
