---
title: Riferimenti
description: Aggiungi directory locali e repository Git come riferimenti di progetto.
---

I riferimenti danno ad Aigcfroge accesso a directory esterne al progetto corrente. Usali per rendere disponibile documentazione, librerie condivise, esempi o un altro repository mentre lavori.

I riferimenti vengono configurati tramite alias in `aigcfroge.json` o `aigcfroge.jsonc`.

```jsonc title="aigcfroge.jsonc"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "references": {
    "docs": {
      "path": "../product-docs",
      "description": "Use for product behavior and documentation conventions",
    },
    "sdk": {
      "repository": "keerzzz/AigcForge-sdk-js",
      "branch": "main",
      "description": "Use for JavaScript SDK implementation details",
    },
  },
}
```

---

## Directory locali

Usa `path` per referenziare una directory locale.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "docs": {
      "path": "../docs",
    },
  },
}
```

I percorsi possono essere:

- Relativi al file di configurazione che definisce il riferimento
- Assoluti, come `/home/user/docs`
- Relativi alla tua home directory, come `~/docs`

Puoi anche usare una scorciatoia a stringa:

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "docs": "../docs",
  },
}
```

## Repository Git

Usa `repository` per referenziare un repository Git. Aigcfroge materializza il repository nella sua cache locale dei repository e rende il sorgente estratto disponibile come directory di riferimento.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "effect": {
      "repository": "Effect-TS/effect",
      "branch": "main",
    },
  },
}
```

`repository` accetta URL Git, riferimenti host/percorso e la scorciatoia GitHub `owner/repo`. Il campo opzionale `branch` seleziona un branch o un ref. Senza `branch`, Aigcfroge usa il branch predefinito del repository.

Puoi usare la scorciatoia a stringa quando non ti serve un branch, una descrizione o altre opzioni:

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "effect": "Effect-TS/effect",
  },
}
```

:::note
I riferimenti Git vengono aggiornati in modo asincrono. Un repository appena configurato potrebbe impiegare qualche istante per completare il cloning o l'aggiornamento.
:::

## Descrivi l'uso

Aggiungi `description` per spiegare quando un agente dovrebbe usare un riferimento.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "design-system": {
      "path": "../design-system",
      "description": "Use when implementing UI components or design tokens",
    },
  },
}
```

Aigcfroge include i riferimenti con descrizione nel contesto dell'agente. Le descrizioni dovrebbero essere brevi e abbastanza specifiche da distinguere riferimenti con contenuti simili. I riferimenti senza descrizione restano disponibili tramite autocomplete e uso diretto, ma non vengono pubblicizzati agli agenti.

---

## Nascondi le voci dell'autocomplete

Imposta `hidden` a `true` per escludere un riferimento dall'autocomplete `@` nella TUI.

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "internal": {
      "path": "../internal",
      "description": "Use for internal implementation details",
      "hidden": true,
    },
  },
}
```

`hidden` influisce solo sull'autocomplete. Un riferimento nascosto con una descrizione resta incluso nel contesto dell'agente.

---

## Usa i riferimenti

I riferimenti configurati compaiono nell'autocomplete `@` della TUI. Digita `@alias` per allegare la root del riferimento, oppure `@alias/` per cercare i file al suo interno.

```text
Compare this implementation with @sdk/src/client.ts
```

Gli agenti ricevono anche i percorsi risolti e le descrizioni dei riferimenti configurati che hanno una descrizione nel loro contesto di sistema, cosi possono ispezionare un riferimento quando e rilevante senza che tu lo alleghi manualmente.

Aigcfroge consente automaticamente le directory di riferimento tramite il suo confine di permesso external-directory. I normali permessi degli strumenti continuano ad applicarsi; per esempio, un agente che non puo modificare file non ottiene accesso in modifica solo perche una directory e configurata come riferimento.

## Campi di configurazione

| Campo          | Locale | Git | Descrizione                                        |
| -------------- | ------ | --- | -------------------------------------------------- |
| `path`         | Si     | No  | Directory di riferimento locale                    |
| `repository`   | No     | Si  | URL Git, host/percorso o valore `owner/repo` di GitHub |
| `branch`       | No     | Si  | Branch o ref Git opzionale                        |
| `description`  | Si     | Si  | Guida che descrive quando usare il riferimento     |
| `hidden`       | Si     | Si  | Nasconde il riferimento dall'autocomplete `@` della TUI |

Gli alias dei riferimenti non possono essere vuoti ne contenere `/`, spazi bianchi, backtick o virgole.
