---
title: Polityki
description: Kontroluj, z jakich skonfigurowanych zasobów może korzystać Aigcfroge.
---

Polityki kontrolują, czy Aigcfroge może wykonać akcję na nazwanym zasobie. Ta funkcja jest eksperymentalna i konfiguruje się ją za pomocą tablicy `experimental.policies` w pliku `aigcfroge.json`.

Polityki są oddzielne od [uprawnień](/docs/permissions). Uprawnienia kontrolują, co narzędzia mogą robić podczas sesji, podczas gdy polityki kontrolują, czy Aigcfroge może korzystać z zasobu takiego jak dostawca LLM.

---

## Konfiguracja

Każda reguła polityki ma trzy pola:

- `effect` — wartość `"allow"` lub `"deny"`.
- `action` — kontrolowana operacja.
- `resource` — identyfikator zasobu lub wzorzec wieloznaczny, którego dotyczy reguła.

Na przykład odmów użycia dostawcy `openai`:

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "experimental": {
    "policies": [
      {
        "effect": "deny",
        "action": "provider.use",
        "resource": "openai"
      }
    ]
  }
}
```

Dostawca zablokowany przez politykę nie jest dostępny do wyboru modelu ani do użycia modelu, nawet jeśli posiada poświadczenia lub jest w inny sposób poprawnie skonfigurowany.

---

## Dostępne polityki

Aigcfroge obsługuje obecnie jedną akcję polityki:

| Akcja          | Zasób                         | Opis                              |
| -------------- | ----------------------------- | --------------------------------- |
| `provider.use` | Identyfikator dostawcy, np. `openai` | Zezwól lub zablokuj użycie dostawcy LLM. |

W przyszłości mogą zostać dodane kolejne akcje polityk.

---

## Dopasowywanie

Pole `resource` obsługuje dopasowywanie wieloznaczne. Użyj `*`, aby dopasować zero lub więcej znaków, oraz `?`, aby dopasować jeden znak.

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "experimental": {
    "policies": [
      {
        "effect": "deny",
        "action": "provider.use",
        "resource": "company-*"
      }
    ]
  }
}
```

To blokuje dostawców takich jak `company-us` i `company-eu`.

---

## Kolejność reguł

Gdy dopasowuje się wiele reguł, wygrywa ostatnia dopasowana reguła. Umieść ogólne reguły na początku, a bardziej szczegółowe wyjątki po nich.

Na przykład zezwól tylko na Anthropic:

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "experimental": {
    "policies": [
      {
        "effect": "deny",
        "action": "provider.use",
        "resource": "*"
      },
      {
        "effect": "allow",
        "action": "provider.use",
        "resource": "anthropic"
      }
    ]
  }
}
```

Jeśli żadna polityka nie pasuje do dostawcy, użycie dostawcy jest domyślnie dozwolone.

Polityki można ustawić zarówno w konfiguracji globalnej, jak i w konfiguracji projektu. Jeśli polityki z obu lokalizacji pasują do tego samego dostawcy, polityka globalna ma pierwszeństwo nad polityką projektu. Zapobiega to ponownemu włączeniu przez repozytorium dostawcy, którego zablokowałeś globalnie.

---

## Listy dostawców

Podczas kontrolowania dostępu do dostawców używaj polityk zamiast starszych ustawień `disabled_providers` i `enabled_providers`.

Aby zastąpić `disabled_providers`:

```json title="aigcfroge.json"
{
  "experimental": {
    "policies": [
      { "effect": "deny", "action": "provider.use", "resource": "openai" },
      { "effect": "deny", "action": "provider.use", "resource": "google" }
    ]
  }
}
```

Aby zastąpić `enabled_providers`, najpierw zablokuj wszystkich dostawców, a następnie zezwól na wybranych dostawców:

```json title="aigcfroge.json"
{
  "experimental": {
    "policies": [
      { "effect": "deny", "action": "provider.use", "resource": "*" },
      { "effect": "allow", "action": "provider.use", "resource": "anthropic" },
      { "effect": "allow", "action": "provider.use", "resource": "openai" }
    ]
  }
}
```
