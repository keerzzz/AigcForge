---
title: 參照
description: 將本機目錄和 Git 儲存庫新增為專案參照。
---

參照讓 Aigcfroge 可以存取目前專案之外的目錄。使用它們可在您工作時提供文件、共享函式庫、範例或其他儲存庫。

參照透過 `aigcfroge.json` 或 `aigcfroge.jsonc` 中的別名進行設定。

```jsonc title="aigcfroge.jsonc"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "references": {
    "docs": {
      "path": "../product-docs",
      "description": "Use for product behavior and documentation conventions",
    },
    "sdk": {
      "repository": "keerzzz/AigcForge-sdk-js",
      "branch": "main",
      "description": "Use for JavaScript SDK implementation details",
    },
  },
}
```

---

## 本機目錄

使用 `path` 參照本機目錄。

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "docs": {
      "path": "../docs",
    },
  },
}
```

路徑可以是：

- 相對於定義參照的設定檔
- 絕對路徑，例如 `/home/user/docs`
- 相對於您的主目錄，例如 `~/docs`

您也可以使用字串簡寫：

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "docs": "../docs",
  },
}
```

## Git 儲存庫

使用 `repository` 參照 Git 儲存庫。Aigcfroge 會將儲存庫具體化到其本機儲存庫快取中，並將簽出的原始碼作為參照目錄提供。

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "effect": {
      "repository": "Effect-TS/effect",
      "branch": "main",
    },
  },
}
```

`repository` 接受 Git URL、主機/路徑參照，以及 GitHub `owner/repo` 簡寫。可選的 `branch` 欄位用於選擇分支或 ref。若未指定 `branch`，Aigcfroge 會使用儲存庫的預設分支。

當您不需要指定分支、描述或其他選項時，可以使用字串簡寫：

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "effect": "Effect-TS/effect",
  },
}
```

:::note
Git 參照會非同步重新整理。新設定的儲存庫可能需要一些時間才能完成克隆或更新。
:::

## 描述用法

新增 `description` 來解釋代理何時應使用某個參照。

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "design-system": {
      "path": "../design-system",
      "description": "Use when implementing UI components or design tokens",
    },
  },
}
```

Aigcfroge 會在代理上下文中包含帶有描述的參照。描述應該簡短且足夠具體，以區分內容相似的參照。沒有描述的參照仍可透過自動補全和直接使用來存取，但不會向代理提示。

---

## 隱藏自動補全項目

將 `hidden` 設定為 `true`，即可從 TUI 的 `@` 自動補全中省略某個參照。

```jsonc title="aigcfroge.jsonc"
{
  "references": {
    "internal": {
      "path": "../internal",
      "description": "Use for internal implementation details",
      "hidden": true,
    },
  },
}
```

`hidden` 只影響自動補全。帶有描述的隱藏參照仍會包含在代理上下文中。

---

## 使用參照

已設定的參照會出現在 TUI 的 `@` 自動補全中。輸入 `@alias` 可附加參照根目錄，或輸入 `@alias/` 以搜尋其中的檔案。

```text
Compare this implementation with @sdk/src/client.ts
```

代理也會在其系統上下文中收到帶有描述的已設定參照之解析後路徑與描述，因此當參照相關時，它們可以檢查該參照，而無需您手動附加。

Aigcfroge 會自動允許參照目錄通過其外部目錄權限邊界。一般的工具權限仍然適用；例如，無法編輯檔案的代理不會因為某個目錄被設定為參照而獲得編輯權限。

## 設定欄位

| 欄位          | 本機 | Git | 描述                                                |
| ------------- | ----- | --- | ------------------------------------------------ |
| `path`        | 是   | 否  | 本機參照目錄                                        |
| `repository`  | 否   | 是  | Git URL、主機/路徑或 GitHub `owner/repo` 值         |
| `branch`      | 否   | 是  | 可選的 Git 分支或 ref                               |
| `description` | 是   | 是  | 描述何時使用該參照的指引                            |
| `hidden`      | 是   | 是  | 從 TUI 的 `@` 自動補全中隱藏該參照                  |

參照別名不能為空，也不能包含 `/`、空白字元、反引號或逗號。
