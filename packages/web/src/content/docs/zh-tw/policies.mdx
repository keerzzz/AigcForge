---
title: 策略
description: 控制 Aigcfroge 可以使用哪些已設定的資源。
---

策略用於控制 Aigcfroge 是否可以對指定資源執行操作。此功能為實驗性功能，透過 `aigcfroge.json` 中的 `experimental.policies` 陣列進行設定。

策略與[權限](/docs/permissions)是分開的。權限控制工具在工作階段期間可以做什麼，而策略控制 Aigcfroge 是否可以使用 LLM 供應商等資源。

---

## 設定

每條策略陳述包含三個欄位：

- `effect` - 值為 `"allow"` 或 `"deny"`。
- `action` - 被控制的操作。
- `resource` - 陳述所套用的資源 ID 或萬用字元模式。

例如，拒絕使用 `openai` 供應商：

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "experimental": {
    "policies": [
      {
        "effect": "deny",
        "action": "provider.use",
        "resource": "openai"
      }
    ]
  }
}
```

被策略拒絕的供應商無法用於模型選擇或模型使用，即使它已設定憑證或其他設定正確。

---

## 可用策略

Aigcfroge 目前支援一種策略操作：

| 操作           | 資源                           | 描述                                     |
| -------------- | ----------------------------- | ------------------------------------- |
| `provider.use` | 供應商 ID，例如 `openai`      | 允許或拒絕使用 LLM 供應商。                |

未來可能會新增更多策略操作。

---

## 比對

`resource` 欄位支援萬用字元比對。使用 `*` 比對零個或多個字元，使用 `?` 比對一個字元。

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "experimental": {
    "policies": [
      {
        "effect": "deny",
        "action": "provider.use",
        "resource": "company-*"
      }
    ]
  }
}
```

這會拒絕 `company-us` 和 `company-eu` 等供應商。

---

## 規則順序

當多條陳述同時比對時，最後比對的陳述優先。將廣泛的規則放在前面，然後在它們之後放置更具體的例外。

例如，僅允許 Anthropic：

```json title="aigcfroge.json"
{
  "$schema": "https://aigcfroge.ai/config.json",
  "experimental": {
    "policies": [
      {
        "effect": "deny",
        "action": "provider.use",
        "resource": "*"
      },
      {
        "effect": "allow",
        "action": "provider.use",
        "resource": "anthropic"
      }
    ]
  }
}
```

如果沒有策略比對到某個供應商，該供應商預設允許使用。

策略可以同時設定在您的全域設定和專案設定中。如果來自兩個位置的策略比對到同一個供應商，您的全域策略優先於專案策略。這可以防止儲存庫重新啟用您在全域拒絕的供應商。

---

## 供應商清單

在控制供應商存取時，請使用策略，而不是較舊的 `disabled_providers` 和 `enabled_providers` 設定。

要取代 `disabled_providers`：

```json title="aigcfroge.json"
{
  "experimental": {
    "policies": [
      { "effect": "deny", "action": "provider.use", "resource": "openai" },
      { "effect": "deny", "action": "provider.use", "resource": "google" }
    ]
  }
}
```

要取代 `enabled_providers`，請先拒絕所有供應商，然後允許選定的供應商：

```json title="aigcfroge.json"
{
  "experimental": {
    "policies": [
      { "effect": "deny", "action": "provider.use", "resource": "*" },
      { "effect": "allow", "action": "provider.use", "resource": "anthropic" },
      { "effect": "allow", "action": "provider.use", "resource": "openai" }
    ]
  }
}
```
