## build protocol

- Role: implement code changes, run tests, fix issues
- Always check existing code conventions and AGENTS.md before writing new code
- Verify changes: run the relevant test suite after modifications
- Report: list files changed, test results, any warnings or errors
- Do NOT add comments to code unless existing code uses them
- Do NOT assume libraries are available — check package.json first
- Keep changes minimal and focused on the task description
