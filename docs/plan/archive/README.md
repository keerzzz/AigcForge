# docs/plan/archive

Landed or superseded planning docs, kept for history. Nothing here is a live
contract — active plans live in `docs/plan/`.

Archival rule (2026-09-20): a plan is archived when it is a one-shot execution
artifact (`prompt-*`, `*-tdd-prompt.md`) whose work has landed AND no live doc
(root protocol, ADR, ARCHITECTURE, technical-debt, roadmap, coverage-manifest,
or another active plan) still references it. Referenced or in-progress plans stay
in `docs/plan/`. Moves use `git mv` so history is preserved.
